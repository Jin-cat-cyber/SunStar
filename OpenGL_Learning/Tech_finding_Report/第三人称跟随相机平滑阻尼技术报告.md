## 1. 背景

`SpaceShip12.0.cpp` 实现了三视角模式：自由相机（模式1）、遥控视角（模式2）、第三人称跟随（模式3）。

模式3 的跟随相机要求：相机位于**飞船后方偏上**，**始终看向飞船**，飞船移动/旋转时相机自动跟随。

飞船状态由 `Spaceship` 结构体维护（`position` + 航向四元数 `heading`），机头方向：

```cpp
glm::vec3 Forward() const { return heading * glm::vec3(0.0f, -1.0f, 0.0f); }  // 模型机头原始朝 -Y
```

---

## 2. 现象

模式3 里，飞船 A/D（偏航）或 R/F（俯仰）**旋转停止的瞬间**，画面会「抽帧」——像朝旋转方向又快速动了一下，肉眼可辨的卡顿。

**关键线索**：模式2（相机位置定格、不跟随）观察同样的飞船旋转，**完全没有这个问题**。

由此可定位：抽帧不是飞船自身（`heading` 没有速度残留、不会「回正」），而是**相机跟随行为**引入的。

---

## 3. 成因

最初的跟随是**硬跟随**——每帧直接把相机位置设为飞船后方偏上的目标点，无任何平滑：

```cpp
camera.Position = ship.position - fwd * followDistance + glm::vec3(0, followHeight, 0);
```

问题出在两个数的乘积上：

| 量 | 值 | 说明 |
|----|-----|------|
| 飞船角速度 | `turnRate=50`，约 0.8°/帧 | 每帧机头转的角度 |
| 跟随半径 | `followDistance=80` | 相机绕飞船转的半径 |

相机绕飞船转的**线速度 ≈ 角速度 × 半径**。飞船每转 0.8°，相机就**瞬移约 1.1 个单位**。旋转停止的瞬间，相机从「绕转中」**瞬时归零**——这一下生硬的突变被眼睛捕捉为抽帧。

本质上：**跟随相机没有任何阻尼/惯性，是「瞬时硬绑定」，飞船的每一次离散旋转都 1:1 地变成相机的一次离散跳变。**

---

## 4. 解决

让相机位置**不瞬移**，而是每帧向目标位置「逼近一点点」，用 lerp 做平滑：

```cpp
// 目标位置（飞船后方偏上）
glm::vec3 target = ship.position - ship.Forward() * followDistance + glm::vec3(0, followHeight, 0);

// 平滑逼近：不瞬移，按比例向 target 靠拢
float t = glm::clamp(followSmooth * deltaTime, 0.0f, 1.0f);
camera.Position = glm::mix(camera.Position, target, t);

// 朝向随 Position 平滑（指向飞船）
camera.Front = glm::normalize(ship.position - camera.Position);
camera.Right = glm::normalize(glm::cross(camera.Front, glm::vec3(0, 1, 0)));
camera.Up    = glm::normalize(glm::cross(camera.Right, camera.Front));
```

### 为什么一处 lerp 同时治好偏航和俯仰

偏航（A/D）和俯仰（R/F）最终都作用在**同一个量**上——`ship.Forward()`（机头方向）。相机目标位置 `target` 和朝向 `Front` 都是它的函数。所以只要把 `Position` 平滑了，`Front` 作为 `Position` 的函数也一并平滑，**两种旋转的抽帧被同一个 lerp 一起消除**，无需分别处理。

---

## 5. followSmooth 调参

`followSmooth` 是阻尼系数：越大跟随越硬（≈瞬移），越小越软（≈滞后）。

| followSmooth | 观感 | 适用 |
|-------------|------|------|
| 2.0 | 明显滞后，船走镜头「慢半拍追」，有**镜头切换的电影感** | 第三人称演出、氛围镜头 |
| 5.0 | 软跟随，能感到「船先动、相机再追」 | 偏叙事的跟随 |
| 10.0 | 中等，基本跟手，抽帧已消除 | 默认手感 |
| 15.0+ | 接近硬跟随，滞后感消失 | 需要相机「钉死」在船后时 |

> 本次最终选用 `followSmooth = 2.0`，保留明显的滞后感作为镜头语言，效果很有趣。

### 进阶：帧率无关的指数平滑

上面的 `followSmooth * deltaTime` 是「简单 lerp」，**帧率相关**（帧率越高逼近越快）。若追求严格一致的手感，用**指数平滑**（帧率无关）：

```cpp
float t = 1.0f - glm::exp(-followSmooth * deltaTime);  // 每帧逼近比例与帧率解耦
camera.Position = glm::mix(camera.Position, target, t);
```

`glm::exp` 保证 `t ∈ [0,1)`，无需 clamp，且「1 秒后的逼近程度」只由 `followSmooth` 决定、与帧率无关。

---

## 6. 可复用要点

> **跟随/追踪相机必须加阻尼。** 硬跟随（每帧直接设目标位置）会把被追踪物体的每次离散运动 1:1 变成相机跳变，物体旋转时尤其明显（相机绕物体的线速度 = 角速度 × 跟随半径，被放大）。

> **平滑相机位置即可顺带平滑朝向。** 若相机朝向是「看向追踪目标」这一条公式（`Front = normalize(target - Position)`），那么朝向就是 Position 的函数，平滑 Position 等于平滑朝向，不必对 Front 单独做平滑。

> **lerp 系数记得 clamp 或用指数平滑。** 简单 `lerp(t = k*dt)` 在 dt 突变时会过冲（t>1），要么 `glm::clamp`，要么换成 `1 - exp(-k*dt)` 的指数平滑（帧率无关且天然 <1）。
