> C++ 加载：`SpaceShip15.0.cpp:180-181`（注意是 **2.0** 目录，不是 1.0）

## 〇、这套环是什么技术

不是几何贴图，是**全屏射线步进（Ray Marching）体积渲染**：从屏幕每个像素往世界空间发一条视线，在"环包围盒"内一步步采样灰尘密度，累加散射光。核心步骤：

1. **重建视线射线**：`invProjView` 把屏幕像素反推回世界空间远点，得射线方向（相机在盒内/盒外/平行看都朝正前方）。
2. **rayBox**：限定在环盒内 march（slab 法求进/出点）。
3. **raySphere**：射线与火星球交点，把 march 截断在火星前表面 —— 根治穿模。
4. **64 步循环**：每步采样点算密度、阴影、散射、透射率。
5. **加法混合**：体积光是发光体，`glBlendFunc(GL_SRC_ALPHA, GL_ONE)` 累加进画面。

## 二、形状 / 浓度分布（密度场的轮廓，shader 循环内）

### 内外缘渐隐 `radial`（约 :142）

```glsl
radial = smoothstep(0.0, 0.15, relDist) * (1.0 - smoothstep(0.6, 1.0, relDist));
```

| 哪个值 | 当前 | 调大 | 调小 |
|---|---|---|---|
| 内缘 `0.15` | 内缘渐隐宽度 | 内缘更柔、收得慢 | 内缘更锐、硬切 |
| 外缘 `0.6` | 外缘开始收 | 外缘更早收、环显窄 | 外缘更晚收、飘散远 |

**作用**：让环边缘渐散而非刀切，**"柔边感"的钥匙**。

### 垂直厚度 `vertical`（约 :143）

```glsl
vertical = exp(-(h*h) / (ringHalfHeight * ringHalfHeight) * 2.0);
```

这里的 **`2.0`** 是高斯的衰减系数：

- **调大**（2.0→3.0）：上下收束更快，环更扁、更利落。
- **调小**（2.0→1.5）：上下张开更厚，环更蓬松、更朦胧。

**作用**：决定环是"薄片"还是"厚雾"。

### 云团大小 `uv`（约 :145）

```glsl
vec2 uv = offset * 0.045;
```

这里的 **`0.045`** 是噪声频率（采样坐标缩放）：

- **调小**（0.045→0.03）：云块更大、更缓、更飘渺。
- **调大**（0.045→0.08）：云块更细碎、颗粒感强。

**作用**：尘埃长成"大雾团"还是"小碎点"。

### 云团多少 / 缝隙 `n`（约 :147-149）

```glsl
n = fbm(uv + vec2(time*0.03, time*0.02));
n = smoothstep(0.3, 0.8, n);
d = radial * vertical * (0.5 + 0.7 * n);
```

| 哪个 | 当前 | 作用 |
|---|---|---|
| `smoothstep(0.3, 0.8, n)` | 0.3, 0.8 | 区间中=云，两端=空/密。**调宽**（0.2,0.9）→ 均匀柔和；**调窄**（0.45,0.65）→ 云缝对比更强 |
| `0.5`（密度基数） | 0.5 | 环整体最低浓度。调高→浓实；调低→稀透 |
| `0.7`（噪声幅度） | 0.7 | 起伏强度。调高→更斑驳；调低→均匀 |

> **注意** `0.5 + 0.7*n` 是一对：改 `0.5` 整体挪，改 `0.7` 改对比度。想看"有云有缝"，调大 `0.7` 调小 `0.5`。

### 云怎么动 `time`（约 :147）

```glsl
uv + vec2(time*0.03, time*0.02)
```

`0.03` / `0.02` 是 x/y 漂移速度。调大→云动得快；调小→缓慢漂浮。

## 三、光照 / 明暗

### 亮暗面 `lit`（约 :156）

```glsl
lit = 0.4 + 0.6 * max(dot(outward, sunDir), 0.0);
```

| 哪个 | 当前 | 作用 |
|---|---|---|
| `0.4` 底光 | 背光半圈基础亮度。**调低**（0.4→0.15）→ 背光更黑、正反面对比更强、立体感；调高→均匀 |
| `0.6` 对比系数 | 朝太阳一面增益。调高→亮面更亮、对比更强 |

**作用**：环"一边被太阳照亮、一边躲进阴影"的立体感来源。

### 散射强度 `0.22`（约 :162）

```glsl
light += sunColor * tint * scatter * stepLen * 0.22;
```

这里的 **`0.22`** 是全局亮度缩放（等效光强）：

- **调大** → 环整体更亮；**调小** → 更暗。
- 太阳侧易过曝（白花花）。压到 0.22 就是防这个。

### 消光 / 厚度 `0.025`（约 :164）

```glsl
transmittance *= exp(-d * stepLen * 0.025);
```

这里的 **`0.025`** 是 Beer-Lambert 消光系数，**决定"实 vs 透"**（只影响透明度，不影响亮度）：

- **调大**（0.025→0.05）→ 环更实、更遮、后面更黑、有厚度。
- **调小**（0.025→0.01）→ 环更透、能看穿到后面星星、像薄纱。

> **`0.22` 和 `0.025` 别搞混**：`0.22` 管**亮不亮**，`0.025` 管**实不实**。

### 颜色 `tint`（约 :159）

```glsl
vec3 tint = mix(vec3(1.0, 0.75, 0.5), vec3(1.0, 0.95, 0.8), smoothstep(0.15, 0.6, relDist));
```

| 当前 | 作用 |
|---|---|
| `vec3(1.0, 0.75, 0.5)` | 内缘颜色（橙红） |
| `vec3(1.0, 0.95, 0.8)` | 中带/外缘颜色（亮白金） |
| `smoothstep(0.15, 0.6, relDist)` | 内→外过渡位置 |

想更暖→第一个往红橙压（如 `1.0, 0.6, 0.4`）；想更冷加蓝（如 `0.9, 0.95, 1.0`）。

### 阴影 `bias`（约 :59）

```glsl
float bias = 21.0;
```

点光源阴影偏移。**用户之前实调（小行星带 21），这次明确说不动它。** 除非环带出明显"T 形伪影/条纹"，否则别改。

## 四、性能 / 画质

| 参数 | 位置 | 当前 | 调大 | 调小 |
|---|---|---|---|---|
| `steps` | :121 | 64 | 更细腻但更慢 | 更快但可能阶梯/条带 |

`steps` 是 ray-march 步数，性能大关节：64 步 × 每步 1 次阴影采样。96-128 画质好但掉帧；32 更快但环可能"一条一条"。

## 五、关键速查表（哪类效果调哪个）

| 想要的效果 | 调哪个 |
|---|---|
| 环整体更**亮** | 散射 `0.22` ↑ |
| 环更**实/遮** | 消光 `0.025` ↑ |
| 环更**厚/立体** | 垂直高斯系数 `2.0` ↓ 或 ringThickness ↑ |
| 环边缘更**柔** | `relDist` 渐隐的两个数 |
| 云团**更大** | 噪声频率 `0.045` ↓ |
| 云比**更强烈** | 噪声幅度 `0.7` ↑ / 密度基数 `0.5` ↓ |
| 背光更**黑**（对比强） | lit 底光 `0.4` ↓ |
| 内缘**暖橙** | 颜色 tint 第一个三元组 |
| 云动得**更快** | 漂移 `0.03/0.02` ↑ |

## 六、注意事项

1. **改 shader 无需重编译**，保存后重跑程序即可（GLSL 运行时加载）。改 `Globals.h` 的几何尺寸才需重编译。
2. **一次只改一个参数**，跑起来看，别一堆一起改。
3. **`bias`、`shadow_far`** 属阴影系统，已定版，**别动**。
4. 调 `0.22`/`0.025` 时留意**太阳侧过曝**——那是亮度上限；`0.025` 不会过曝，只会变实。
