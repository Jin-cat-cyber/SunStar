## 0. 引言

本文从**体积参与介质（participating media）**出发，逐项推导 `atmo_frag.shader` 里实际落地的那一套**单次散射**数学：渲染方程、Beer–Lambert 透射率、瑞利/米氏相位函数、以及把它离散成 Ray-March 的数值积分。每个公式都标注了它对应到代码里的哪一行，方便对照理解。

---

## 1. 散射模型：单次散射渲染方程

沿视线方向收集到的出射辐射度，等于**背景被衰减后的透过光**加上**沿途介质散射进视线的光**：

$$
L_{out} \;=\; T(P\!\to\!E)\,L_{bg} \;+\; \int_{t_0}^{t_1} T(P\!\to\!x)\,T(x\!\to\!E)\,\sigma_s(x)\,\Phi_{sun}\,p(\theta_x)\,ds
$$

**符号表**

| 符号 | 含义 |
|---|---|
| $P,\;E,\;x$ | 视线起点（相机）、终点、路径上一点 |
| $s$ | 沿视线的弧长参数 |
| $L_{bg}$ | 大气背后的背景（星空/太阳） |
| $\sigma_s(x)$ | 散射系数（瑞利 + 米氏） |
| $\Phi_{sun}$ | 太阳入射光强（代码 `sunColor`） |
| $p(\theta)$ | 相位函数 |
| $T(a\!\to\!b)$ | 透射率：光从 $a$ 传到 $b$ 幸存的比例 |

我们的实现是**单散射 + 无光程消光**的简化版，下面把每个子项逐一展开。

---

## 2. 透射率：Beer–Lambert 定律

介质的吸收与散射使光沿途指数衰减：

$$
T(a\!\to\!b) \;=\; \exp\!\Big(-\!\int_a^b \sigma_t(x)\,\rho(x)\,ds\Big),
\qquad
\sigma_t \;=\; \sigma_s + \sigma_a
$$

其中 $\sigma_t$ 是消光系数，$\sigma_a$ 是吸收系数。

### 2.1 代码近似：$\sigma_a \approx 0$

你只算散射，忽略吸收，因此消光全由散射贡献：

$$
\sigma_t \;=\; \sigma_{Rayleigh} + \sigma_{Mie} \;=\; \mathrm{rayleighCoef} + \mathrm{miecoef}
$$

### 2.2 数值积分（中点法）

沿视线逐步累加透射率，每步乘一次：

$$
T_{i+1} \;=\; T_i \,\cdot\, \exp\big(-\sigma_t\,\rho(x_i)\,\Delta s\big)
$$

对应代码（逐通道 vec3）：

```glsl
// atmo_frag.shader 主循环内
transmittance *= exp(-(rayleighCoef + vec3(miecoef)) * heightDensity * stepLen);
```

这里 `heightDensity` 就是 $\rho(x)$（见 §3），`stepLen` 就是 $\Delta s$。

## 3. 散射系数与高度密度

### 3.1 瑞利系数：与波长四次方成反比

$$
\beta_R \;\propto\; \frac{1}{\lambda^4}
$$

蓝光波长最短、被散射得最狠，所以大气边缘偏蓝。代码里的谱分布即"蓝 > 绿 > 红"：

```glsl
rayleighCoef = (0.05, 0.08, 0.2)   // B 通道最大 → 蓝偏
```

### 3.2 米氏系数：近似与波长无关

尘埃/雾滴尺度接近或大于波长，散射接近中性：

```glsl
miecoef = 0.02f
```

### 3.3 高度密度：指数标高大气

定义归一化高度

$$
h \;=\; \frac{r - R}{R}
$$

其中 $r$ 是采样点到行星中心距离，$R$ 是行星半径（$h=0$ 贴地表）。密度为：

$$
\rho(h) \;=\; \exp\!\big(-h\,k\big) \cdot \rho_0
$$

令标高 $\Lambda = R/k$，可直接改写成经典形式：

$$
\rho(r) \;=\; \rho_0 \exp\!\Big(-\frac{r - R}{\Lambda}\Big)
$$

`k` 就是你调过的 `falloff`：

| `falloff` | 标高 $\Lambda=R/k$ | 视觉 |
|---|---|---|
| 大 | 小 | 大气薄、锐、贴边 |
| 小 | 大 | 大气厚、软、弥漫 |

对应代码：

```glsl
float h = length(p - planetCenter) / planetRadius - 1.0;
float heightDensity = exp(-hAtmo * falloff) * density;
```

## 4. 相位函数 $p(\theta)$

相位函数描述"某个方向入射的光，散射到偏离 $\theta$ 角方向的相对强度"。设视线方向 $\hat V$、阳光方向 $\hat L$，相位角余弦：

$$
\cos\theta \;=\; \hat V \cdot \hat L
$$

对应代码：

```glsl
float cosAngle = dot(rd, normalize(sunDir));
```

### 4.1 瑞利相位（前后对称）

$$
p_R(\theta) \;=\; \frac{3}{16\pi}\big(1 + \cos^2\theta\big),
\qquad
\frac{3}{16\pi} \approx 0.0596831
$$

- 归一化系数来源：$\int_{4\pi} p_R\,d\omega = 1$。
- 在 $\cos\theta=\pm 1$（正对或背对光源）取最大、$\cos\theta=0$（垂直）最弱 → 产生**前后对称的柔和蓝白边**。

```glsl
return 0.0596831 * (1.0 + cosTheta * cosTheta);
```

### 4.2 米氏相位（Henyey–Greenstein，强前向峰）

$$
p_M(\theta) \;=\; \frac{1}{4\pi}\cdot\frac{1-g^2}{\big(1 + g^2 - 2g\cos\theta\big)^{3/2}},
\qquad
\frac{1}{4\pi}\approx 0.0795775
$$

- $g$ 是**各向异性参数**：$g>0$ 表示光强烈沿入射方向（前方）散射；
- $g=0.72$ 时，$\theta\to 0$（$\cos\theta\to 1$）的峰值可达 $\approx 1.7$，远超 1；
- 这正是**背光透光晕**的来源：相机望向太阳时 $\cos\theta\to+1$，前向峰把光绕着火星轮廓散射进镜头 → 轮廓外**暖白亮弧**。

```glsl
float g = 0.72;
return 0.0795775 * ((1.0 - g*g) / pow(1.0 + g*g - 2.0*g*cosTheta, 1.5));
```

## 5. 离散化：Ray-March 积分

把 §1 的体积积分用**中点法**离散为求和：

$$
L_{out} \;\approx\; \sum_{i=0}^{N-1} \Big[ \sigma_s(x_i)\,\Phi_{sun}\,p(\theta_i)\,T(P\!\to\!x_i) \Big]\,\Delta s
$$

逐行对应主循环：

```glsl
vec3 localScatter = (rayleigh + mie) * sunColor * transmittance;   // σ_s·Φ·p(θ)·T(cam→x)
scatter += localScatter * stepLen;                                 // 累加 · Δs
transmittance *= exp(-σ_t · ρ · Δs);                               // 更新 T
```

也就是每一步：先按当前位置的 $\rho(x)$ 与 $p(\theta)$ 算出"此地散射进视线的光量"，再乘"光从相机走到这儿还剩多少（$T$）"，再乘步长累加进积分。

## 6. 两个近似及其视觉后果

1. **丢弃"阳光→采样点"的光程消光 $T(x\!\to\!\text{sun})$**
   完整版还要乘这一项，使亮侧更亮、暗侧更暗、出现晨昏线渐变。你曾实现过"光程消光版"，但实测与简洁版区别不大且更耗性能，于是回退。**后果**：大气整体偏均匀，亮暗对比主要靠 $p(\cos\theta)$ 区分朝向，立体感有限；想要更强立体感可重新启用。

2. **消光系数合并 $\sigma_t \approx \sigma_s$（无单独吸收）**
   单散射常用近似，视觉上够用。

## 7. 为什么"边缘亮、背光亮、盘面微霾"

散射量正比于路径上累积的 $\sigma_s\,\rho\,\Delta s$，**视线在大气里的路径长度**是关键：

- **盘面中心射线**：近垂直穿过薄壳，路径短、$\rho$ 只在贴地表时大 → 累积少 → **盘面淡薄雾**；
- **贴轮廓切线射线**：贴大气掠行，路径极长且多在密度大的低层 → 累积骤增 → **边缘亮环**（行星大气最抢眼的"边缘发光"）；
- **背光侧 + 米氏前向峰**：切线光在 $\cos\theta\to+1$ 时再乘 $\approx1.7$ 的前向峰 → **轮廓外暖白亮弧**。

> 结论：边缘亮不是系数大，而是**长路径 × 高密度**叠加的结果；调 `falloff`（密度标高）与 `atmoScale`（壳厚）就是在控制亮环的厚薄与锐度。

## 8. 参数与物理量速查表

| 代码变量 | 物理量 | 控制效果 |
|---|---|---|
| `rayleighCoef` | $\beta_R \propto 1/\lambda^4$ | 蓝偏边 / 边缘蓝紫 |
| `miecoef` | $\beta_M$（波长无关） | 暖白前向散射 / 透光弧强度 |
| `density` | $\rho_0$ | 大气总密度 |
| `falloff` | $k = \Lambda / R$（标高倒数） | 大→薄锐贴边；小→厚软弥漫 |
| `atmoScale` | 壳外半径 $R\cdot\text{atmoScale}$ | 大气壳整体大小 |
| `g` | 米氏各向异性 | 透光弧强弱/峰尖 |
| $\cos\theta = \hat V\cdot\hat L$ | 相位角 | 亮暗朝向 |
