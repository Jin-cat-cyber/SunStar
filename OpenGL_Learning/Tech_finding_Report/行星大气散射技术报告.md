# 行星大气散射 · 技术报告

> 版本：SpaceShip16.0.cpp + `res/shader/00_SpaceShip/Atmosphere/`（atmo_ver.shader / atmo_frag.shader）
> 定稿日期：2026-09-07

---

## 一、目标

给火星加一层"真正的大气散射"——瑞利/米氏散射，边缘透光晕 + 背光透红。区别于之前火星表面已有的菲涅尔边缘光（`rimColor` 淡蓝，只是"贴表面"的轮廓光，不是真大气）。

---

## 二、方案选型

**A. 物体空间散射（贴火星表面）**
- 在 `planet_frag.shader` 里从表面沿视线向外 ray-march。
- 优点：改动集中、性能好；缺点：**做不出"背光透光晕"**（大气延伸不到火星背后）。

**B. 独立大气壳（火星外层套大气球壳）** ← **采用**
- 火星外层套一个更大的透明大气球（半径 = `planetRadius * atmoScale`），独立 pass 渲染。
- 优点：能出**背光透光晕**，大气是完整"笼罩"的，亮暗侧 + 背后透光都能做。
- 缺点：改动更大（新 pass + 新 shader），要处理火星本体遮挡。

> 用户明确要"背光透光晕"，故选 **B**。

---

## 三、最终实现（简洁版，定稿）

### 渲染流程
1. 全屏 quad（复用 `quadVAO`），重建视线射线 `rd`（`invProjView`）。
2. `raySphere` 求视线与**大气壳**（半径 `atmoR = planetRadius * atmoScale`）的进出点。
3. `raySphere` 求视线与**火星球**（半径 `planetRadius`）交点，若击中则把 march 终点 clamp 到火星表面（大气被火星本体遮挡）。
4. 沿视线 march 32 步，累加瑞利 + 米氏散射，用 Beer-Lambert 消光。
5. 加法混合 `GL_SRC_ALPHA, GL_ONE` 输出（HDR，可进 bloom）。

### 核心公式
- **瑞利散射**（大气主色，蓝偏）：`rayleigh = rayleighCoef * heightDensity * phaseRayleigh(cosAngle)`
  - 相位函数：`0.0597 * (1 + cos²θ)`，θ = 视线方向与太阳方向的夹角。
- **米氏散射**（雾、前向散射）：`mie = miecoef * heightDensity * phaseMie(cosAngle)`
  - 相位函数：Henyey-Greenstein，`g = 0.72`。
- **高度密度衰减**：`heightDensity = exp(-h * 4.0) * density`，h = 到行星表面的归一化高度。
- **Beer-Lambert 消光**（相机→采样点）：`transmittance *= exp(-(rayleighCoef + miecoef) * heightDensity * stepLen)`（vec3 逐通道）。

### 定稿参数（C++ L860-867）
| 参数 | 值 | 作用 |
|---|---|---|
| `atmoScale` | 1.5f | 大气壳 = 火星半径 1.5 倍 |
| `rayleighCoef` | (0.05, 0.08, 0.2) | 瑞利散射系数（蓝偏） |
| `miecoef` | 0.005f | 米氏散射系数 |
| `density` | 1.0f | 大气总密度开关 |
| `sunColor` | (1.0, 0.9, 0.75) | 太阳散射光色 |
| `sunDir` | normalize(太阳 - 行星) | 从行星指向太阳 |

## 四、踩过的坑

1. **`transmittance` 类型**：初版写成 `float`，但 Beer-Lambert 消光用了 `vec3` 系数，触发 `C7623 implicit narrowing` 链接错误。改成 `vec3 transmittance`（逐通道消光，物理上也更正确——蓝光消光强、红光弱）。

2. **`sunDir` 方向反了**：初版 `cosAngle = dot(rd, sunDir)`，但 `sunDir` 存的是"行星→太阳"，而散射相位函数需要"光从太阳射来"的方向，导致亮暗面反。修成 `cosAngle = dot(rd, -normalize(sunDir))`。

3. **散射系数太小看不见**：初版 `rayleighCoef = (0.005, 0.008, 0.02)` 太小，加上大气壳薄，散射光弱到被火星已有的 `rimColor` 蓝边淹没。调试时暴力放大 100 倍（0.5, 0.8, 2.0）确认效果出来，再收敛到 (0.05, 0.08, 0.2)。

---

## 五、尝试过但弃用的方案（光程消光版）

在简洁版基础上，每步采样点**再朝太阳方向 march 16 步**，算"阳光从大气顶到该点的透射率" `lightTransmittance`，散射乘上它——理论上亮侧亮、暗侧暗、有晨昏线渐变。

**实测结果**：用户反馈"和上一版（简洁版）没什么区别，反而更耗性能"，故**弃用，回退到简洁版**。

> 保留记录原因：这是大气散射的"完整版"思路，若以后觉得简洁版太均匀、想要更强立体感，可重新启用（把 `lightTransmittance` 那段循环加回来即可）。

---

## 六、已知取舍

- 简洁版**没有"光程消光"**，所以大气整体偏均匀，亮暗侧对比不强（主要靠相位函数 cosθ 区分朝向），"立体感"有限。
- 蓝色通道 2.0（测试值）会过强，收敛后 0.2 已自然。若想要更偏红/更偏蓝，调 `rayleighCoef` 三个分量比例即可。
- 大气散射是 HDR 值，会参与 bloom，边缘晕带发光感。
