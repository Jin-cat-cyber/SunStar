## 1. 现象描述

在延迟 PBR 渲染中，当漫反射 IBL 的 `irradianceMap`（辐照度图）未正确绑定，导致片元着色器实际用**原始环境贴图 `envCubemap`** 采样时，物体表面呈现出**环境的清晰倒影**（如房间窗户、天花板结构等锐利图案），而非预期的柔和漫反射环境光。

**视觉特征：**

- 物体像"镜子"般映出环境的清晰图案
- 画面比固定 ambient 常量更丰富、有反射感
- 无卷积，计算量小，实现简单

---

## 2. 成因分析

着色器中的采样代码（`pbr_frag2.0.shader`）：

```glsl
vec3 irradiance = texture(irradianceMap, N).rgb;   // N = 表面法线
```

当 `irradianceMap` 采样器实际绑定的是 `envCubemap`（原始环境贴图）时，对比：

| 采样对象 | 内容 | 视觉结果 |
|---------|------|---------|
| 原始环境贴图 `envCubemap`（锐利）| 每个方向的精确光 | 镜面反射感（清晰倒影）|
| 卷积辐照度图 `irradianceMap`（模糊）| 半球光的加权平均 | 柔和漫反射 |

**核心结论**：用表面法线 `N` 直接索引未卷积的 cubemap，等价于"把环境贴图直接投影到物体表面"，因此呈现出反射外观。

---

## 3. 技术本质

该现象对应一类经典实时渲染技术——**环境映射（Environment Mapping）**，具体属于**反射映射（Reflection Mapping）** 的近似变体。

| 变体 | 采样方向 | 效果 | 物理正确性 |
|------|---------|------|-----------|
| 标准反射映射 | `R = reflect(-V, N)` | 正确的镜面反射 | ✅ |
| 法线近似（本现象）| `N`（法线）| 近似反射，廉价 | ❌ 近似 |
| 漫反射 IBL | `N`（卷积图）| 柔和环境光 | ✅ |

**为什么用法线 N 采样也能"看起来不错"**：

对于球体这类凸物体，法线方向从表面中心向外辐射，与环境贴图的立方体结构天然对齐。因此"用法线索引环境贴图"近似于"从表面观察环境"，尤其对曲率平缓的表面，能产生可接受的反射感。

---

## 4. 适用场景

| 场景 | 是否适用 |
|------|---------|
| 金属 / 光滑表面（镜面反射感）| ✅ 理想（配合反射向量 `R` 更好）|
| 需要廉价"环境着色"的物体 | ✅ 无卷积开销 |
| 粗糙 / 岩石表面（漫反射）| ❌ 应使用卷积后的 irradianceMap |
| 需要物理准确的 PBR | ❌ 本技术非物理 |

---

## 5. 局限

1. **非物理**：用法线 N 采样是近似，不是正确的镜面反射（正确应用 `R = reflect(-V, N)`）
2. **无粗糙度控制**：反射永远"锐利"，无法表现粗糙表面的模糊反射
3. **依赖环境贴图质量**：环境贴图的细节会直接暴露在物体表面
4. **与漫反射语义冲突**：它占据的是 ambient（环境光）项，但表现的是反射

---

## 6. 可复用的实现方案

### 方案 A：正确反射映射（推荐）

用反射向量替代法线，得到物理正确的镜面反射：

```glsl
vec3 V = normalize(camPos - WorldPos);
vec3 R = reflect(-V, N);                        // 反射向量
vec3 reflection = texture(envCubemap, R).rgb;    // 正确的采样方向
```

### 方案 B：加粗糙度模糊（多 mip 近似）

粗糙表面反射应该模糊，用 cubemap 的 mip level 近似：

```glsl
vec3 R = reflect(-V, N);
vec3 reflection = textureLod(envCubemap, R, roughness * 8.0).rgb;
// roughness 越高 → mip 越高 → 越模糊
```

### 方案 C：法线采样（保留当前效果，零改动）

直接用法线 N 采样原始环境贴图（即当前"bug"），作为廉价环境着色：

```glsl
vec3 env = texture(envCubemap, N).rgb;   // 法线近似反射
```

---

## 7. 结论

这个"bug"本质上是**环境映射技术**的一次无意实现。它证明了：

> 未卷积环境贴图 + 方向采样 = 反射外观

作为"廉价反射 / 环境着色"手段，它在非物理、性能敏感、需要反射感的场景有实际价值；但若要物理准确，应改用反射向量 `R` 并配合粗糙度（即镜面 IBL 的 prefilter 思路）。

## 8. 附录：相关代码

### 8.1 现象触发代码（PBR_IBL1.A.cpp）

渲染循环中**缺失**了 irradianceMap 的绑定，导致采样到 envCubemap：

```cpp
pbrShader.use();
glm::mat4 view = camera.GetViewMatrix();
pbrShader.setMat4("view", view);
pbrShader.setVec3("camPos", camera.Position);

// 缺少下面两行 → irradianceMap 实际采样到 envCubemap
// glActiveTexture(GL_TEXTURE0);
// glBindTexture(GL_TEXTURE_CUBE_MAP, irradianceMap);
```

### 8.2 采样代码（pbr_frag2.0.shader）

```glsl
vec3 irradiance = texture(irradianceMap, N).rgb;
vec3 diffuse    = irradiance * albedo;
vec3 ambient    = (kD * diffuse) * ao;
```

### 8.3 环境贴图转换流程

```
HDR equirectangular → envCubemap（原始，锐利）
                    → irradianceMap（卷积，模糊，漫反射 IBL）
```
