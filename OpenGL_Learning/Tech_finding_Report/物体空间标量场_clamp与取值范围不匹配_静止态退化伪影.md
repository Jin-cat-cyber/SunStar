# `clamp` 与取值范围不匹配：静止态退化伪影的完整案例

> 一份工程错误的全过程记录，按顺序走完五步：**现象、排除法定位、机理、"为什么加 epsilon 是错的修法"、正确的修法**。
> 载体是折跃特效的溶解前沿，但结论与那段代码无关，属于"把带噪声的坐标夹进定区间"这类构造的通病。
>
> 前置阅读：`物体空间标量场_电流细丝与轴向溶解的数学原理.md`（尤其是 §5.3 关于水平集、§9.5 关于噪声抖动）。

---

## 1. 现象

折跃尚未启动（**没有按 `T`**）时，舰体**艏部**出现一块青绿色覆盖区。特征：

| 观察项 | 表现 |
|---|---|
| 位置 | 只在艏部，不延伸到舰体中后段 |
| 颜色 | 均匀的青绿，没有贴图细节、没有可见的金属/粗糙度变化 |
| 边界 | 参差不齐，像被噪声啃过，而不是一条直线 |
| 触发条件 | **与 `T` 无关**；程序一启动就存在，静止时永远在 |
| 其余功能 | 按 `T` 之后的折跃过程本身正常 |

---

## 2. 先确认"这块青绿是什么"

代码里能让一片像素同时变成"青绿 + 表面平整 + 无贴图细节"的只有一处 —— **材质剥离区**的着色：

```glsl
albedo    = mix(albedo,    uDissolveColor * 0.15, stripped);
metallic  = mix(metallic,  0.0,  stripped);
roughness = mix(roughness, 1.0,  stripped);
N         = mix(N, normalize(Normal), stripped);
```

三件事一一对上：

1. **青绿**：`uDissolveColor * 0.15`，取 `uDissolveColor = (0.25, 0.95, 0.80)` 得 `(0.0375, 0.1425, 0.12)` —— 偏绿的低亮度色。
2. **没有贴图细节**：法线被换成几何法线（`normalize(Normal)`），法线贴图的高频细节被丢掉。
3. **表面平整**：粗糙度被拉到 1，金属度归零。

所以结论很干脆：**那块像素的 `stripped` 等于 1。**

于是问题变成：**静止时 `stripped` 为什么会是 1？**

---

## 3. 定位：把可能性一条条排除

静止时 $\tau = 0$，于是四个输入都是确定的：

$$
u_{\text{vanish}} = 0, \qquad
d_{\text{geo}} = \texttt{geoFront}(0) = 0, \qquad
d_{\text{mat}} = \texttt{matFront}(0) = 0
$$

（前两个等号来自 `wch.v = 0` 与两条前沿的 `r = 0`。）

代码里与 `stripped` 有关的只有三条路径，逐条看：

**路径 (a)：`discard`。**

```glsl
if (gt < uFrontGeo) discard;
```

静止时是 `gt < 0`。而 `gt = clamp(..., 0, 1)`，恒有 `gt ≥ 0`，所以这个条件**恒不成立**。
结论：这块区域**不是**"被剔除之后剩下的东西"。排除。

**路径 (b)：`stripped` 本身。**

```glsl
float stripped = 1.0 - smoothstep(uFrontGeo, uFrontMat, gt);
```

静止时是 `1.0 - smoothstep(0.0, 0.0, gt)`。分两种情况：

- `gt > 0`：`smoothstep` 内部是 $\mathrm{clamp}\bigl((gt-0)/(0-0)\bigr) = \mathrm{clamp}(+\infty) = 1$，于是 `stripped = 1 - 1 = 0` —— 正确，不剥离。
- `gt = 0`：$(0-0)/(0-0) = 0/0$ —— **未定义**。

**路径 (c)：切口发光。**

```glsl
float band = 1.0 - smoothstep(0.0, uEdge, abs(gt - uFrontGeo));
float win  = smoothstep(0.0, 0.05, uFrontGeo) * smoothstep(0.0, 0.05, 1.0 - uFrontGeo);
```

`win` 的第一个因子是 `smoothstep(0, 0.05, 0) = 0`，所以 `win = 0`，`warpGlow = 0`。而且它还要乘 `uVanish = 0`。
结论：这块青绿**不是发光**（是材质本身被改了）。排除。

**排除完只剩一条路：路径 (b) 里 `gt = 0` 的那一支。**

于是问题收敛成一句话：**为什么静止时会有一大片像素的 `gt` 恰好等于 0？**

---

## 4. 机理

### 4.1 数学上，`gt = 0` 是一个面积为零的集合

`gt` 是一个连续标量场：$g$ 是位置的线性函数，噪声 $n$ 是连续函数，两者相加再乘常数，仍连续。$g_t$ 的某个取值对应的集合是它的一个**水平集** —— 在二维表面上是一条曲线，**面积为零**。

用一个更直白的说法：一个像素的 `gt` 恰好取到 0 这个精确值，概率是零。

**"这个退化输入不会真的出现"这个假设，来源就在这里。** 它本身没错 —— 错的是下一步。

### 4.2 `clamp` 把"面积为零"变成了"有面积"

```glsl
float gt = clamp(g + uNoiseW * (noise3(q * uNoiseFreq) - 0.5), 0.0, 1.0);
```

`clamp` 在 0 处的行为是：**所有算出来小于 0 的像素，全部被赋成同一个值 0。**

那么"被赋成 0"的集合有多大？把条件写出来。记 $w = $ `uNoiseW` $= 0.25$，噪声 $n \in [0,1]$，轴向坐标 $g \in [0,1]$：

$$
g + w\left(n - \tfrac12\right) \le 0
\iff
g \le w\left(\tfrac12 - n\right)
$$

右端是正数才可能有解，故需 $n \le \tfrac12$。于是被压平的集合是

$$
A = \left\{\, (g,\, n) \in [0,1]^2 \;:\; n \le \tfrac12,\quad 0 \le g \le w\left(\tfrac12 - n\right) \,\right\}
$$

它的面积（在 $(g,n)$ 单位正方形上取二重积分，内层对 $g$ 积分只是乘上区间长度）：

$$
\lvert A \rvert
= \int_0^{1/2} w\left(\tfrac12 - n\right) \, \mathrm{d}n
= w\left[\tfrac{n}{2} - \tfrac{n^2}{2}\right]_0^{1/2}
= w \cdot \tfrac18
= 0.25 \times 0.125
= 0.03125
$$

（第一个等号是把内层积分做完；第二个等号是代入上下限，$\tfrac{1}{4} - \tfrac{1}{8} = \tfrac18$；第三个等号代入 $w = 0.25$。）

**面积 $0.03125$ —— 正的，占单位正方形的 3.125%。**

而且 $A$ 里 $g$ 的上界是 $g \le w/2 = 0.125$，即**只落在艏部 12.5% 的舰长之内**。

> **这就是整件事的关键一步：`clamp` 把一个"面积为零的等值线"换成了一个"面积为正的平台"。**
> 上一节的假设（"退化输入不会真出现"）在这一步当场失效，而且失效的规模是可见的一整块。

这也解释了现象里那两条特征：**为什么在艏部**（$g$ 小的地方才满足条件）、**为什么边缘参差**（$A$ 的边界 $g = w(1/2 - n)$ 是随噪声起伏的曲线）。

### 4.3 退化的 `smoothstep`

GLSL 规范对 `smoothstep(edge0, edge1, x)` 的定义是

$$
t = \mathrm{clamp}\!\left(\frac{x - \text{edge0}}{\text{edge1} - \text{edge0}},\ 0,\ 1\right),
\qquad
\mathrm{smoothstep} = t^2(3 - 2t)
$$

当 $\text{edge0} = \text{edge1}$ 时分母为 0。规范对此是明确的：

> **`edge0 ≥ edge1` 时结果未定义。**

静止时恰好 $d_{\text{geo}} = d_{\text{mat}} = 0$，正命中这个条件。各驱动的实现通常就是上面那个式子，于是：

| 情形 | 分子 / 分母 | `t` | `stripped` |
|---|---|---|---|
| $gt > 0$ | 正数 / 0 = $+\infty$ | clamp 到 1 | $0$（正确） |
| $gt = 0$ | 0 / 0 = NaN | clamp(NaN) 未定义 | **实测为 $1$** |

反过来看这条表，还能确认一件事：**如果驱动给的是 NaN 而不是 0，`mix(albedo, 青绿, NaN)` 会得到 NaN，通常渲染成纯黑或纯白。** 截图里是干净的青绿，说明驱动给的是 0 —— 也就是 `stripped = 1`。这条反推同时验证了整个定位链条。

### 4.4 为什么偏偏在静止态

两条前沿相等只发生在 $r = 0$，即 $\tau = 0$，即**折跃根本没有启动**的时候。

按"边界情况"的直觉，这该是最不容易撞到的路径。但事实上：

> **静止态是程序的稳态。** 折跃只在按键之后的 $1.25$ 秒内发生，其余全部时间 $\tau = 0$。所以这条"只在某一帧出现"的路径，实际上是 99.9% 的时间都在执行的路径。

它最显眼，也最不在任何测试里 —— 因为写代码和调特效时人都在盯着"按了 T 之后"看。

**由此得到一条通用检查法**：想用"这个退化输入不会真出现"去豁免一段代码之前，先问一句 ——

> **这些参数在哪个状态下同时取到各自的极端？那个状态是不是恰恰是常态？**

## 5. 为什么"加一个 epsilon"是错的修法

最直觉的修法是给 `smoothstep` 的边界加一个最小间距：

```glsl
float stripped = 1.0 - smoothstep(uFrontGeo, max(uFrontMat, uFrontGeo + 0.02), gt);
```

它确实消除了"`edge0 == edge1`"这个未定义调用。但**它没有修掉缺陷**，只是把缺陷缩小到不易察觉：

静止时 $a = 0$、$b = 0.02$，于是

- $g_t = 0$：$\mathrm{smoothstep}(0,\,0.02,\,0) = 0$，得 `stripped = 1` —— **那块青绿还在**；
- $g_t \in (0,\ 0.02)$：`stripped` 由 1 降到 0 —— 只是多出一条更窄的带。

也就是说，这个修法把"面积为 3.125% 的平台"换成了"面积更小但依然存在的平台"。**因为缺陷的根源不是那个未定义调用本身。**

根源在 §4.2：`clamp` 制造了一块 $g_t = 0$ 的平台。而 `stripped = 1 - smoothstep(a, b, gt)` 的语义是

> $g_t \le a$ 的像素被判定为"完全剥离"。

静止时 $a = 0$，而平台的 $g_t$ 恰好等于 $0$ —— **平台正落在"完全剥离"这一侧的上边界上**。加 epsilon 并没有把 $a$ 从 0 挪开（$a$ 就是 $u_{\text{FrontGeo}} = 0$），所以平台仍在判定区内。

要真正修掉，必须做到下面两件事之一：

1. **让平台不存在** —— 不再有面积为正的 $g_t = 0$ 区域；或
2. **让"完全剥离"的判定区在静止时是空集** —— 即 $a$ 严格小于平台的值。

只加 epsilon，两件都没做到。

> **教训：看到一个"未定义调用"时，先分清它是缺陷本身，还是缺陷的**症状**。**
> 这里它只是症状 —— 真正的问题是那个调用被喂进了一个"本不该有面积"的输入。

---

## 6. 正确的修法：让两个取值范围对齐

两件事必须一起做。

### 6.1 让平台不存在：不夹 $g_t$

由 §4.1，$g_t = 0$ 本该是面积为零的水平集，**那就不该夹它**。去掉 `clamp` 之后，$g_t$ 的取值范围完全由 $g$ 与 $n$ 的范围决定：

$$
g_t = g + w\left(n - \tfrac12\right) \in \left[-\tfrac{w}{2},\ 1 + \tfrac{w}{2}\right] = [-0.125,\ 1.125]
$$

（下界取自 $g = 0$、$n = 0$；上界取自 $g = 1$、$n = 1$。）

平台消失 —— $g_t = 0$ 重新变回一条面积为零的曲线。

### 6.2 让静止时的判定区为空：前沿取满同一个范围

去掉 `clamp` 之后 $g_t$ 可以取到负值。**若前沿还留在 $[0,1]$ 里，负值那一侧就会被误判为"已被扫过"** —— 缺陷会换个方向再来一次。

所以前沿必须**取满同一个范围**。记

$$
d_{\text{lo}} = -\frac{w}{2} = -0.125, \qquad
d_{\text{hi}} = 1 + \frac{w}{2} = 1.125, \qquad
\ell = 0.06
$$

其中 $\ell$ 是材质对几何的固定**空间**领先量。用一个进度 $r \in [0,1]$ 给出两条前沿：

$$
d_{\text{geo}}(r) = (d_{\text{lo}} - \ell) + (d_{\text{hi}} - d_{\text{lo}} + \ell)\, r,
\qquad
d_{\text{mat}}(r) = d_{\text{geo}}(r) + \ell
$$

两端验算：

| $r$ | $d_{\text{geo}}$ | $d_{\text{mat}}$ | 剔除 $g_t < d_{\text{geo}}$ | 完全剥离 $g_t \le d_{\text{geo}}$ |
|---|---|---|---|---|
| $0$（静止） | $-0.185$ | $-0.125$ | $g_t$ 的下界是 $-0.125$，**恒不成立** | 恒不成立 |
| $1$（完成） | $1.125$ | $1.185$ | $g_t$ 的上界是 $1.125$，**恒成立** | 恒成立 |

第一行就是本次的修复目标：**静止时两条判定全为假 —— 没有任何像素被剔除，也没有任何像素被剥离。**

而且它**不靠 epsilon** —— 靠的是 $-0.185$ 严格小于 $g_t$ 的下界 $-0.125$。

第二行顺带解决了另一个本来会冒出来的问题：$1.125$ 严格大于 $g_t$ 的上界，所以完成时不会在舰艉留下一条没被剔除的细边。

### 6.3 附带好处：一个手调魔数被精确公式取代

修复前的版本里有个手调常数 `FRONT_OVER = 1.02`，本意是"让几何前沿多冲一点，免得艉部残留"。而由上面的推导，**这个值是可以精确算出来的**：噪声上界是 $1 + w/2 = 1.125$，所以越冲量不该是 $1.02$。

新方案里这个常数直接消失，被 $d_{\text{hi}}$ 吸收了。

> 一个手调魔数被精确公式取代、代码行数反而减少，通常就是修对了的证据。

## 7. 同一处构造的第二次翻车：末端的边界反转

在发现静止态伪影**之前**，同一个 `smoothstep(d_geo, d_mat, gt)` 已经在另一端咬过一次。

那时两条前沿是"两条各自 $0 \to 1$ 的斜坡"，而 `FRONT_OVER = 1.02` 只加在几何前沿上：

| $\tau$ | $d_{\text{mat}}$ | $d_{\text{geo}}$ | |
|---|---|---|---|
| $0.63$ | $0.9657$ | $0.9444$ | 正常（$d_{\text{mat}} > d_{\text{geo}}$） |
| $0.64$ | $0.9910$ | $0.9998$ | **交叉** |
| $0.65$ | $1.0000$ | $1.0200$ | 交叉 |

交叉区间是 $\tau \in [0.637,\ 0.65)$，约 $0.013\ \mathrm{s}$ —— 60 fps 下不到一帧。

当时的判断是"只有一两帧、$g_t$ 也已接近 1、实际可忽略"。这个判断本身没错，**但它漏掉了同一处构造在另一个端点上的灾难性后果**。

两次翻车的根因是同一个：

> **一个带前置条件（$\text{edge0} < \text{edge1}$）的调用，要在参数的每一个极值上都验一遍，而不是只看当时正在看的那一处。**

如果当时就把"两条前沿是否始终满足 $d_{\text{geo}} < d_{\text{mat}}$"当成不变量去检查，两次都会在写代码时被发现 —— 而不是一次靠推理放过、一次靠目视才发现。

---

## 8. 可复用的检查清单

任何"把带噪声（或任何非单调量）的坐标夹进定区间，再拿去和阈值比较"的构造，都按这四条过一遍。

**第一，夹取（`clamp` / `saturate`）会不会把面积为零的集合变成面积为正的平台？**
把"被夹到边界值"的集合写出来算一下面积。只要面积为正，这个平台上每个像素都会以**完全相同**的值参与后续判定 —— 退化输入从此"真的会出现"。

**第二，与它比较的阈值，取值范围是否覆盖了那个量在不夹时的完整范围？**
这是本次的核心。两者的域不匹配，误判就必然出现在某一端 —— 不在这里，就在那里。

**第三，带前置条件的函数调用，前置条件在参数的每个极值上成立吗？**
`smoothstep(a, b, x)` 要 $a < b$；除法要分母非零；`normalize` 要长度非零；`pow` 要底数非负。逐个极值验，别只看当前那一个中间态。

**第四，那些极端值是不是恰好出现在静止态 / 初始态？**
极端值同时出现的位置往往就是程序的**稳态**。稳态比边界更容易被撞到，却最不容易被测试覆盖 —— 因为写代码和调特效时，人都在盯着"触发之后"看。
