## 1. 背景

飞船需要三种观察/操控方式，分别覆盖太空场景最常见的三种视角：

| 模式 | 相机 | 键盘 |
|------|------|------|
| 1 自由相机 | 自由飞行 | WASD 控制相机，飞船不动 |
| 2 遥控视角 | 位置定格 + 环顾 | WASD/RF/QE/ZX 控制飞船 |
| 3 第三人称跟随 | 跟随飞船后方偏上 | 同上控制飞船，相机自动跟 |

核心是**同一组键在不同模式下有不同语义**，需要一个清晰的状态机 + 输入分发。

---

## 2. 三模式状态机

用一个 `enum` + 一个全局 `currentMode` 表示模式：

```cpp
enum ViewMode { MODE_FREE = 1, MODE_REMOTE = 2, MODE_FOLLOW = 3 };
inline ViewMode currentMode = MODE_FREE;   // Globals.h
```

数字行 1/2/3 直接切换（比循环切换直观，且不跟 Tab 冲突）：

```cpp
if (glfwGetKey(window, GLFW_KEY_1) == GLFW_PRESS) currentMode = MODE_FREE;
if (glfwGetKey(window, GLFW_KEY_2) == GLFW_PRESS) currentMode = MODE_REMOTE;
if (glfwGetKey(window, GLFW_KEY_3) == GLFW_PRESS) currentMode = MODE_FOLLOW;
```

> 模式切换是**幂等**的（重复设同一值无害），所以不需要按键上升沿检测，直接 `== GLFW_PRESS` 即可。

## 3. 输入按模式分发

`processInput` 里把移动键按模式分流：

```cpp
if (currentMode == MODE_FREE) {
    // 模式1：WASD 控制相机
    if (W) camera.ProcessKeyboard(FORWARD, deltaTime);
    if (S) camera.ProcessKeyboard(BACKWARD, deltaTime);
    ...
}
else {
    // 模式2/3：设置飞船的目标速度/角速度
    if (W) ship.targetSpeed = ship.forwardMax;
    if (S) ship.targetSpeed = -ship.backwardMax;
    if (A) ship.targetYawAV = ship.turnRate;
    ...
}
```

数字键盘也按模式分流——模式1/2 转相机，模式3 改 orbit 偏移：

```cpp
if (currentMode == MODE_FOLLOW) {
    if (KP_4) orbitYaw += 50.0f * deltaTime;    // 模式3：环顾
    ...
}
else {
    if (KP_4) camera.ProcessKeyboardRotate(1.0f, deltaTime);  // 模式1/2：转相机
    ...
}
```

**可复用要点：输入分发用「模式判断 + if/else」即可，不需要为每个模式各写一套输入函数。** 同一组键在不同模式下的语义差异，集中在这一处 if/else 里最清晰。

## 4. 跟随相机与 orbit 环顾

### 跟随相机（细节见平滑阻尼报告）

模式3 每帧把相机放到飞船后方偏上、看向飞船，并用 lerp 平滑：

```cpp
if (currentMode == MODE_FOLLOW) {
    glm::vec3 target = ship.position - ship.Forward() * followDistance + glm::vec3(0, followHeight, 0);
    float t = glm::clamp(followSmooth * deltaTime, 0.0f, 1.0f);
    camera.Position = glm::mix(camera.Position, target, t);   // 平滑逼近

    // 看向飞船 + orbit 环顾偏移
    glm::vec3 toShip = glm::normalize(ship.position - camera.Position);
    glm::quat orbitRot = glm::angleAxis(glm::radians(orbitYaw),   glm::vec3(0,1,0)) *
                         glm::angleAxis(glm::radians(orbitPitch), glm::vec3(1,0,0));
    camera.Front = orbitRot * toShip;
    camera.Right = glm::normalize(glm::cross(camera.Front, glm::vec3(0,1,0)));
    camera.Up    = glm::normalize(glm::cross(camera.Right, camera.Front));
}
```

### orbit 环顾

模式3 里相机默认"看向飞船"，数字键盘 4/6/8/2 改 `orbitYaw`/`orbitPitch`，在"看向飞船"的基础上叠加一个环绕偏移，实现**边跟随边环顾**。默认偏移 0 = 纯看向飞船。

---

## 5. 可复用要点

> **多模式操控用「enum + 全局 currentMode + if/else 分发」。** 状态机不需要类，一个 enum 加全局变量就够；输入分发集中在 processInput 的一处 if/else，同一组键的多模式语义一目了然。

> **跟随 + 环顾 = 位置跟随 + 朝向叠加偏移。** 相机位置跟随目标（lerp 平滑），相机朝向 = 「看向目标」再叠加一个 orbit 四元数偏移。两者解耦，环顾不影响跟随位置，默认偏移 0 就是纯跟随。

> **模式切换键选数字行 1/2/3 而非循环键。** 直接跳转比循环切换直观，且不占用 Tab（Tab 常被用于解锁鼠标）。
