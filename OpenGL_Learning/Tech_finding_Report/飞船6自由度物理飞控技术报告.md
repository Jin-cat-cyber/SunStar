## 1. 背景

`SpaceShip12.0.cpp` 的飞船用 `Spaceship` 结构体维护状态：`position`（位置）+ `heading`（航向四元数）。目标是实现太空飞行手感——**不是"按键瞬间满速、松手瞬间停"，而是带惯性的匀加速运动**：起步加速、松手滑停、转向有角加速度。

为此把飞船控制从「方法式」（`MoveForward/Yaw/...` 直接改位置）重构为「状态式」：**按键只设目标值，`Update` 每帧统一做匀加速逼近 + 积分位移 + 积分旋转。**

---

## 2. 匀加速逼近模型（速度平滑）

### 核心：一个 `approach` 辅助函数

所有速度类状态（前进/后退/升降/角速度）都用同一个「向目标逼近、最多逼近 `rate*dt`、夹在目标处」的模型：

```cpp
static float approach(float cur, float target, float rate, float dt)
{
    float step = rate * dt;                        // 这一帧最多变这么多
    if (cur < target) return glm::min(cur + step, target);  // 加速，但不超过目标
    if (cur > target) return glm::max(cur - step, target);  // 减速，但不越过目标
    return cur;
}
```

### 物理意义

`cur` 向 `target` 以斜率 `rate` 逼近，等价于**匀加速直线运动**：速度线性变化、到达目标后匀速。加速度 `rate` 按方向选不同值：

```cpp
// 前进：加速 accel、后退 backwardAccel、松开减速 decel
float fwdRate = (targetSpeed > 0) ? accel : (targetSpeed < 0) ? backwardAccel : decel;
speed = approach(speed, targetSpeed, fwdRate, dt);

// 位移：沿机头方向积分速度
position += Forward() * speed * dt;
```

### 效果与参数

| 参数 | 默认 | 含义 |
|------|------|------|
| `forwardMax` / `backwardMax` | 30 / 10 | 前进/后退速度阈值（后退小，符合喷口在后的物理） |
| `accel` | 20 | 前进加速度 a |
| `decel` | 30 | 松手后的减速率 |
| `backwardAccel` | 8 | 后退加速度 a1（\|a1\| < a） |

## 3. 角加速度与匀加速圆周

旋转和位移**同一套模型**：维护「当前角速度」和「目标角速度」，角速度用 `approach` 匀加速逼近，再积分角速度得到旋转角——这就是**匀加速圆周运动**。

```cpp
// 角速度向目标匀加速逼近（三个轴共用 angularAccel）
yawAV   = approach(yawAV,   targetYawAV,   angularAccel, dt);
pitchAV = approach(pitchAV, targetPitchAV, angularAccel, dt);
rollAV  = approach(rollAV,  targetRollAV,  angularAccel, dt);

// 积分角速度 → 旋转增量四元数
glm::quat dYaw   = glm::angleAxis(glm::radians(yawAV)   * dt, ...);
glm::quat dPitch = glm::angleAxis(glm::radians(pitchAV) * dt, ...);
glm::quat dRoll  = glm::angleAxis(glm::radians(rollAV)  * dt, ...);
```

单位：`turnRate = 10` 是角速度阈值（**度/秒**），`angularAccel = 20` 是角加速度（**度/秒²**）——从静止转到满速需 `10/20 = 0.5 秒`，这就是"转向有惯性、松手角速度匀减速到零"的来源。

## 4. 四元数乘序：左乘世界 vs 右乘局部

这是全篇最核心、也最容易搞错的一点。

### 规则

| 写法 | 轴在哪套坐标系 | 直觉 |
|------|--------------|------|
| `d * q`（**左乘**） | **世界轴** | d 加在 q 的"外面"，绕世界固定轴转 |
| `q * d`（**右乘**） | **局部轴** | d 加在 q 的"里面"，绕飞船自身轴转 |

**记忆：左乘 = 世界，右乘 = 局部。**

### 应用：6 自由度飞控应该全部右乘

太空飞行里"偏航/俯仰/滚转"都是**相对飞船自身姿态**的，所以标准做法是三个旋转都**右乘（局部轴）**：

```cpp
heading = glm::normalize(heading * dYaw * dPitch * dRoll);  // 全部右乘
```

### 踩过的坑

最初 `dPitch` 用了**左乘世界 X 轴**（`dYaw * dPitch * heading * dRoll`），结果按 R/F 俯仰变成了"右斜向上/左斜向下"——因为飞船的 right 轴在世界里是斜的，绕世界 X 轴转混进了偏航成分。**把 `dPitch` 移到右乘（绕飞船局部 right）后，俯仰才变回纯抬头/低头。**

## 5. 模型三轴非标准对齐

这个 GLB 飞船模型的局部坐标轴**不是标准对齐**，是踩坑重灾区：

| 方向 | 局部轴 | 说明 |
|------|--------|------|
| 机头 Forward | **-Y** | "头朝下"，导入后不旋转的原始朝向 |
| 上方 Up | **-Z** | 舰岛方向（不是 +Y！） |
| 右侧 Right | +X | `Forward × Up` |

```cpp
glm::vec3 Forward() const { return heading * glm::vec3(0.0f, -1.0f, 0.0f); }  // -Y
glm::vec3 Up() const      { return heading * glm::vec3(0.0f, 0.0f, -1.0f); }  // -Z
```

摆正后机头朝世界 **-Z**（朝太阳）。因为 forward 不是标准 -Z、up 不是标准 +Y，所有"绕局部轴"的旋转轴都要按这个非标准三轴来写，不能想当然用 `(0,1,0)`/`(1,0,0)`/`(0,0,1)`。

**教训：模型三轴以运行时实测为准，不要纸上推导。** 曾因反复在 Y/Z 和正负号上出错，最终统一以"键盘操作直觉"（A左D右、R上F下）定方向符号。

## 7. 可复用要点

> **速度/角速度平滑统一用「逼近目标」模型。** 一个 `approach(cur, target, rate, dt)` 函数能处理所有带惯性的量（平移速度、角速度），`rate` 按方向/加减速选不同值即可，代码极简且物理正确。

> **旋转务必分清左乘/右乘。** 左乘 `d*q` 绕世界轴，右乘 `q*d` 绕局部轴。太空/飞行 6 自由度飞控应全部右乘（局部轴），否则飞船一旦俯仰/滚转，"偏航"就不再是相对飞船自身的转向。

> **模型轴非标准对齐时，别用默认轴。** 先实测确定 forward/up 的局部方向（这个 GLB 是 forward=-Y、up=-Z），再据此写旋转轴和位移轴；方向正负以键盘手感为准，不要纸上推导。

> **角加速度让转向有"手感"。** 角速度用 `approach` 匀加速逼近目标角速度，配合 `turnRate`（角速度阈值）+ `angularAccel`（角加速度），转向就有"起步有惯性、松手匀减速"的真实感。
