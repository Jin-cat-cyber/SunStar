## 0. 一句话

**光柱是长在舰体体积内、沿折跃轴线伸长的细长发光方块。**内端钉在出生点上，外端朝中垂面背离的一侧伸长；
它平时埋在舰体里，靠舰体溶解被露出来（去程）、靠材质恢复被盖回去（抵达）。

---

## 1. 观察记录

以下是本方案的**唯一依据**（逐帧观察，按阶段记录）。

### 1.1 去程

1. 光柱**只在半透明带里出现** —— 即两条前沿 `geoFront`（几何剔除，透明那一侧）与 `matFront`（材质剥离，半透明那一侧）之间那一条带；
2. 它们**沿折跃轴线**（舰体局部 $Y$）伸长，**没有随机朝向**；
3. **以中垂面分界**：在它前面的朝舰首方向伸长，在它后面的朝舰尾方向伸长；
4. 漂移是**向外发散**的小幅移动，轴向方向也按分界划分：舰尾那一小段（约 1/4 舰长）向舰尾漂，其余向舰首漂；
5. 缓缓移动之后消失。

### 1.2 抵达

1. 光柱**先出现**（早于材质），密集、长短不一、沿纵向；
2. 舰体材质**出现一半时停止出现新的**光柱；
3. 整体向折跃前进方向**缓慢移动很小的距离**，同时向外发散。

## 2. 机制

### 2.1 一根光柱是什么

一个沿舰体局部 $Y$ 拉长的立方体。三个轴都是舰体局部轴：$X$、$Z$ 是横截面（细），$Y$ 是半长（长）。
出生点取在**舰体体积内部** —— 埋在体内是有意的，见 2.2。

### 2.2 "随波出现"与"被材质盖住"是深度测试白送的

光柱这一层走加法混合、**不写深度**，但**保留深度测试**，并且**画在舰体 pass 之后**（碎屑那一层已经是这个位置）。
于是对任意像素：

| 舰体在该处的状态 | 深度缓冲 | 光柱片元 |
|---|---|---|
| 仍然不透明 | 已写入 | 深度测试失败，不绘制 |
| 在抖散带里 | 只有未被 `discard` 的片元写了深度 | 从抖散孔里透出来，块状、若隐若现 |
| 已被整块剔除 | 没有写入 | 通过测试，整根可见 |

**命题 1**：光柱的可见性完全由舰体的深度缓冲决定，不需要任何"按前沿逐根开关"的逻辑。

**推论 1.1**：去程的"随半透明波扫过出现"与抵达的"被材质盖住"都是自动的。
**推论 1.2**：出生时刻的作用因此只剩一个 —— 给这根柱子的漂移与淡出起表。

这条同时说明为什么不需要给光柱加"溶解门"：舰体自己就是那道门。
（外壳当初那次翻车正是因为外壳**没有**这道门、又活到了舰体之外；光柱不存在这个问题。）

## 3. 符号约定

| 符号 | 含义 | 取值或来源 |
|---|---|---|
| $\tau$ | 折跃唯一时钟 | `gWarp.tau` |
| $g$ | 舰体归一化轴向坐标 | 0 = 舰首，1 = 舰尾 |
| $y$ | 舰体局部轴向坐标（世界单位） | 舰首 $-L/2$，舰尾 $+L/2$ |
| $L$ | 舰长 | 实测 $53.669$ |
| $B$ | `shipBoundR`（包围球半径） | 实测 $27.077$ |
| $\text{FRONT\_LO}$ | 前沿取值域的噪声下界 | $-0.125$ |
| $\text{FRONT\_HI}$ | 前沿取值域的噪声上界 | $1.125$ |
| $\text{FRONT\_LEAD}$ | 材质前沿领先几何前沿的空间量 | $0.25$ |
| $S$ | 前沿跨度 | $\text{FRONT\_HI} - \text{FRONT\_LO} + \text{FRONT\_LEAD} = 1.5$ |
| $r(\tau)$ | 前沿归一化进度 | $[0,1]$，去程单调升 |
| $x$ | 扫描归一化时间 | $x = (\tau - \text{FRONT\_GEO\_START}) / \text{SCAN\_TIME}$ |
| $\tau^\ast$ | 传送时刻 | $1.10$ |
| $p_0$ | 光柱出生点（世界单位，舰体局部系） | 见 §6 |

**$g$ 与 $y$ 的换算。**探针实测 `origin_from_bow = 0.500`，即模型原点落在舰体正中，因此

$$g = \frac{y + L/2}{L}$$

代入 $L = 53.669$，得 $y = -26.834$ 对应 $g = 0$、$y = +26.834$ 对应 $g = 1$。

> 这一条是**实测**而非假设。早先版本曾按"原点可能偏离"做两手准备，探针出来之后可以确定用上式。
> 顺带一条：$B = 27.077$ 比轴向极值 $26.834$ 大 $0.243$，因为包围球的极值点虽在艏端、却**离轴约 $3.6$**
> （$\sqrt{B^2 - 26.834^2} = 3.618$）。所以 $B$ 只是"约等于半舰长"，两者相差 $0.9\%$，本方案对
> 这个量级的误差不敏感。

## 4. 出生规则

### 4.1 去程：由半透明波扫到的时刻决定

两条前沿的定义（见 `WarpSC.h`）：

$$\text{geoFront}(\tau) = (\text{FRONT\_LO} - \text{FRONT\_LEAD}) + S \cdot r(\tau) \tag{1}$$

$$\text{matFront}(\tau) = \text{geoFront}(\tau) + \text{FRONT\_LEAD} \tag{2}$$

把 (1) 代入 (2)：

$$\text{matFront}(\tau) = (\text{FRONT\_LO} - \text{FRONT\_LEAD}) + S \cdot r(\tau) + \text{FRONT\_LEAD} = \text{FRONT\_LO} + S \cdot r(\tau) \tag{3}$$

（依据：$- \text{FRONT\_LEAD} + \text{FRONT\_LEAD} = 0$。）

**命题 2**：轴向位置为 $g$ 的光柱，其出生时刻 $t_0$ 是方程 $\text{matFront}(t_0) = g$ 的解。

**求解。**把 (3) 代入命题 2 的条件：

$$\text{FRONT\_LO} + S \cdot r(t_0) = g$$

移项并除以 $S$：

$$r(t_0) = \frac{g - \text{FRONT\_LO}}{S} = \frac{g + 0.125}{1.5} \tag{4}$$

又 $r = \text{smoothstep01}(x) = 3x^2 - 2x^3$，其反函数取标准恒等式

$$x = \frac{1}{2} - \sin\!\left(\frac{1}{3}\arcsin(1 - 2r)\right) \tag{5}$$

（验算三个端点：$r = 0$ 得 $\arcsin 1 = \pi/2$，故 $x = \frac{1}{2} - \sin\frac{\pi}{6} = 0$；
$r = \frac{1}{2}$ 得 $\arcsin 0 = 0$，故 $x = \frac{1}{2}$；
$r = 1$ 得 $\arcsin(-1) = -\pi/2$，故 $x = \frac{1}{2} + \frac{1}{2} = 1$。三个端点都精确。）

于是

$$t_0 = \text{FRONT\_GEO\_START} + x \cdot \text{SCAN\_TIME} \tag{6}$$

（解析反解，不需要数值迭代。）

**数值代入。**$\text{FRONT\_GEO\_START} = \text{TAU\_STAR} - \text{SCAN\_TIME} = 0.95$（按当前 `T_CHARGE = 1.35`、`T_VANISH = 0.20`、`SCAN_TIME = 0.60`）。

| $g$ | 位置 | (4) 的 $r$ | (5) 的 $x$ | (6) 的 $t_0$ |
|---|---|---|---|---|
| $0$ | 舰首 | $0.0833$ | $0.1775$ | $1.0565$ |
| $1$ | 舰尾 | $0.7500$ | $0.6736$ | $1.3542$ |

即**出生窗 $[1.0565,\ 1.3542]$，从舰首扫到舰尾**，与观察到的"随半透明波扫过出现"一致。
（$r$ 与 $x$ 两列只取决于 $g$，与四段时长无关；只有 $t_0$ 随 $\text{FRONT\_GEO\_START}$ 整体平移。所以改四段时长时这两列不用重算。）

**寿命。**一律夹到窗口末：

$$\text{life} = \min\!\big(P\_\text{LIFE},\ \tau^\ast - t_0\big) \tag{7}$$

约束 §8.1。$P\_\text{LIFE} = 0.50$：舰首那根取左项（$0.50$），舰尾那最后一根取右项（$\tau^\ast - 1.3542 = 1.55 - 1.3542 = 0.1958$）。

### 4.2 抵达：出生窗由两件可观测的事夹出来

$$\text{出生开始} = \text{WIRE\_GROW\_TIME} + \text{HOLD\_TIME} = 4.89 \quad(\text{骨架长满后，静止等待结束}) \tag{8}$$

$$\text{出生截止} = \text{T\_WIRE\_END} + \frac{1}{2}\,\text{FILL\_TIME} = 5.14 \quad(\text{舰体材质出现一半}) \tag{9}$$

$$\text{活动结束} = P\_\text{ARRIVE\_T1} = \text{T\_TOTAL} = 5.62 \quad(\text{与线框同一时刻消失}) \tag{10}$$

$$\text{life} = P\_\text{ARRIVE\_T1} - t_0 \qquad(\text{抵达段不夹 } P\_\text{LIFE})$$

出生时刻在 (8) 与 (9) 之间按哈希铺开，于是**寿命落在 $5.62 - 5.14 = 0.48$ 到 $5.62 - 4.89 = 0.73$ 之间**。这里**故意不夹 $P\_\text{LIFE}$**：抵达段的收尾由全局包络负责（§5.5），夹短会让柱子在消失之前先停下。

> (8) 曾经写成 $\text{WIRE\_GROW\_TIME}$ 本身（骨架刚长满就出光柱）。(8) 现在的形式是对齐 SC2 录屏之后改的：参考画面里骨架长满之后还空了约 $2.87$ 秒才出现光柱，(10) 当时还加过 $+0.23$（SC2 的光柱在材质填满之后似乎残留约 $0.23$ 秒）；**2026-10-02 已改成 $P\_\text{ARRIVE\_T1} = \text{T\_TOTAL}$** —— 那个 $+0.23$ 会让光柱早于线框 $0.10$ 秒消失，而核对画面之后确认它们是**同一时刻**收掉的。对照表见 §7.3。
>
> 另外注意抵达段的**出生先后与位置无关**（出生时刻在出生窗里按哈希铺开），这点与去程相反 —— 去程的出生时刻由半透明波扫到的位置决定（§4.1）。这一点在 §5.5 的全局长度包络里同样成立：长度只随**时间**走，与位置无关。

## 5. 方向规则

光柱身上有三个**互相独立**的方向量，必须分开给，不能混。这是本方案最容易做错的地方
（早先的讨论里就把"伸长"与"漂移"混成了一条）。

### 5.1 伸长方向：以中垂面分

$$\text{dirY} = \begin{cases} -1, & p_{0y} < 0 \quad \text{（中垂面之前，朝舰首伸长）} \\[2pt] +1, & p_{0y} \ge 0 \quad \text{（中垂面之后，朝舰尾伸长）} \end{cases} \tag{11}$$

**为什么必须朝最近那一端伸。**设出生点在 $y = -20$（艏段），柱半长上限 $14$：

- 外端朝舰首伸时柱跨越 $[-34, -20]$，而舰首端在 $y = -26.834$，故**探出舰体之外**；
- 外端朝舰尾伸时柱跨越 $[-20, -6]$，**整根埋在体内**。

也就是说：**伸长方向决定了柱子是否探出舰体两端**，只有朝最近那一端伸才会读出"从舰体里长出来"。
以中垂面分界正是让两端各自的柱子都朝最近那一端伸，于是两端都探出，形成对称的爆发。

**实测确认（2026-09-28）。**`dirY` 的正负与朝向曾经被记反过，所以做了一次极端取值验证：把 $P\_\text{DIR\_Y\_K}$ 设成 $\mp 1.0$，阈值 $K \cdot B = \mp 27.077$ 就被推到出生板 $\pm 0.12\,B = \pm 3.25$ 之外，于是全部柱子倒向同一侧。结果：

| $P\_\text{DIR\_Y\_K}$ | 全部 `dirY` | 伸长朝向 | 画面 |
|---|---|---|---|
| $-1.0$ | $+1$ | 局部 $+Y$，**舰尾** | 全部落在**背对**折跃方向那一侧 |
| $+1.0$ | $-1$ | 局部 $-Y$，**舰首** | 全部落在**朝向**折跃方向那一侧 |

由此定下（与 (11) 一致）：`dirY = -1` 是**朝向折跃方向**，`dirY = +1` 是**背对折跃方向**。
（本节原来还说"它是 §5.5 那条长度随方向演化判据的依据" —— 那条趋势**已作废**，见 §5.5。`dirY` 现在的唯一用途是**伸长方向**，以及去程的漂移分界。）

验证完把 $P\_\text{DIR\_Y\_K}$ 改回 $0$（中垂面）。

### 5.5 抵达段的柱长：由**全局时间表**决定

> **2026-10-02 改**。本节原写的是"柱长沿**出生先后 × 方向**演化"（`dirLen`，见下方留档）。核对 SC2 录屏之后确认那条**不存在**：抵达段的尺寸差异来自"**越晚出生越小**"，而这是**全局时间表**的结果，不是每根柱子各乘一个倍率 —— 而且方向那一维没有任何依据。

抵达段**只有一族**：出生窗 $[4.89,\ 5.14]$，此后不再出生。长度与亮度都由同一条全局曲线 $f(\tau)$ 控制：

$$f(\tau) = \begin{cases} 1 + (P\_\text{LEN\_K1} - 1)\,\sigma\!\left(\dfrac{\tau - P\_\text{ARRIVE\_T0}}{P\_\text{ARRIVE\_BIRTH\_T1} - P\_\text{ARRIVE\_T0}}\right), & \tau \le P\_\text{ARRIVE\_BIRTH\_T1} \\[8pt] P\_\text{LEN\_K1}\left(1 - \sigma\!\left(\dfrac{\tau - P\_\text{ARRIVE\_BIRTH\_T1}}{P\_\text{ARRIVE\_T1} - P\_\text{ARRIVE\_BIRTH\_T1}}\right)\right), & \tau > P\_\text{ARRIVE\_BIRTH\_T1} \end{cases} \tag{11'}$$

其中 $\sigma$ 是 `smoothstep01`。两段的物理含义：

- **拐点**取 $P\_\text{ARRIVE\_BIRTH\_T1} = 5.14$（材质恢复一半），此处 $f = P\_\text{LEN\_K1}$（现值 $0.50$）—— 参考画面里"长条形态"到这一刻基本消失，之后剩下的是**同一批柱子缩短后的"小碎块"**；
- **终点**取 $P\_\text{ARRIVE\_T1} = \text{T\_TOTAL} = 5.62$（线框消失），此处 $f = 0$。

**横截面不跟长度同比例缩**，而是按 $f^{\,P\_\text{ARRIVE\_WIDE\_P}}$ 缩（现值 $P\_\text{ARRIVE\_WIDE\_P} = 0.70$）：
指数取 $1$（与长度同比例）实测**太细**，取 $0$（完全不缩）又是"长度缩了、横截面不缩"，读成**矮胖的板**。
$0.70$ 是实调值。指数 $< 1$ 时两端仍然**同时归零**，所以不会在中途被压成一张看得见的薄片 —— 这一点是"消失时还是长方体"的保证。

**出生后的生长**用绝对秒数：$P\_\text{ARRIVE\_GROW\_T} = 0.06$ 秒内由 $0$ 长满；**淡入**同理用 $P\_\text{ARRIVE\_FADE\_T} = 0.06$ 秒。两者都乘在上面的 $f$ 之外。

**留档（已作废）**：旧方案给每根柱子乘一个由出生先后与伸长方向共同决定的倍率

$$\text{dirLen}(w, \text{dirY}) = \begin{cases} \text{lerp}(P\_\text{FWD\_LEN\_K0},\ 1,\ \sigma(w)), & \text{dirY} < 0 \\[2pt] \text{lerp}(1,\ P\_\text{BACK\_LEN\_K1},\ \sigma(w)), & \text{dirY} \ge 0 \end{cases}$$

函数 `pillarDirLenScale` 与常量 `P\_\text{FWD\_LEN\_K0}` / `P\_\text{BACK\_LEN\_K1}` 都留在头文件里、带"未使用"标记，以便回退。

**⚠️ 半长的坑（旧版本踩过，仍然适用）**：$P\_\text{LEN\_MIN}$ / $P\_\text{LEN\_MAX}$ 是**半长**。顶点着色器算的是 `aPos * aHalf` 而 `aPos ∈ [-1, 1]`，所以 `half[1]` 就是半长。第一版把 $13.4$（全长）填了进去，"最长 = 舰长 $1/4$"实际变成"舰长 $1/2$"。

### 5.2 轴向漂移

**去程**：按可调分界 $y_d$ 分

$$\text{axialDir} = \begin{cases} -1, & p_{0y} < y_d \\[2pt] +1, & p_{0y} \ge y_d \end{cases} \tag{12}$$

$y_d$ 是**独立于 (11) 的常量**。第一版取 $y_d = 0$（与中垂面一致，前后各半）；若实测"向后的那群明显偏少"，
把它挪到 $y_d = +0.5\,B \approx +13.54$（对应 $g = 0.75$，即舰尾 $1/4$ 向后）。

> 两个分界分开的理由：观察记录 1.3 说的是**伸长**以中垂面分，1.4 说的是**漂移**里有一小段向后。
> 若两者都取中垂面，向后漂的比例恒为 $50\%$；若漂移单独取 $g = 0.75$，向后漂的只有 $25\%$。
> 由于原点实测在正中，"$50\%$ 对 $25\%$"这个差别只能由这两个量用不同的分界来解释，或者由后续画面确定其一。

**抵达**：统一向舰首（折跃前进方向）

$$\text{axialDir} = -1 \tag{13}$$

### 5.3 径向漂移

从中轴向外：方向取出生点横向分量 $(p_{0x}, p_{0z})$ 归一化；出生点几乎落在轴线上时（模长小于 $10^{-4}$）
用哈希角度顶上，与碎屑同一套退化处理。

### 5.4 位移模型：按**速度 × 寿命**给

> **2026-10-02 改**。本节原写的是"按总位移给，不按速度"，理由是"按速度给会让寿命长的漂得远"。**已推翻**：柱子寿命长短不一（抵达 $0.48$~$0.73$、去程 $0.196$~$0.494$），按总位移给会让**短命的那批漂得飞快、长命的那批慢悠悠**，同一束里读出两种速度。

$$\vec{d}[1] = \text{axialDir} \times V \times \text{life}, \qquad s(\text{phase}) = \text{phase} \tag{14}$$

| 段 | $V$ | 寿命范围 | 总位移 |
|---|---|---|---|
| 抵达 `P_ARRIVE_DRIFT_SPEED` | $45$ | $0.48$ ~ $0.73$ | $21.6$ ~ $32.9$ |
| 去程 `P_DEPART_DRIFT_SPEED` | $20$ | $0.196$ ~ $0.494$ | $3.9$ ~ $9.9$ |

时间形状**两段都取线性**（原来去程用 `smoothstep01`）：位移是"速度 × 寿命"，乘上线性的 phase 之后**速度恰好与时间无关**，读起来才是"一股稳定的流"；缓入缓出会让柱子在起步与收尾时忽快忽慢。

**径向**仍按总位移给（$|\vec{d}_{\text{radial}}| \in [0.8,\ 2.4]$ 世界单位，见 §5.3）——它只负责散开，不参与"水流"的读法。

**（旧值留档）** 轴向曾按总位移给 $|\vec{d}_{\text{axial}}| \in [1.0,\ 3.0]$；后来抬到 $[4.0,\ 10.0]$ 觉得幅度对了，但"短命飞快、长命慢悠悠"这个毛病随幅度一起放大，于是改成速度制。常量 `P_DISP_AXIAL_MIN` / `_MAX` 已在头文件里注释留档。

**抵达段的最远点到不了线框。** 柱子朝前伸出的总长 $=$ 位移 $+ 2 \times$ 轴向半长，而终点那一刻长度已缩到 $0$，所以约束落在寿命末端：$45 \times 0.73 \approx 32.9$，即最深到离落点约 $34.8$，而线框尾端在 $26.8$ —— 进不去。

**不能用碎屑的 $b(x) = x(2-x)$。** 那是"被甩出去"的形状（$b'(0) = 2$，起步最快、末速为零），与这里的匀速是两回事。

## 6. 几何与生长

| 量 | 取法 | 依据 |
|---|---|---|
| 出生点轴向 | $p_{0y} \in [-0.95B,\ +0.95B]$ | 覆盖 $96\%$ 的半舰长（$0.95 \times 27.077 = 25.72$ 对 $26.834$），够用 |
| 出生点横向 | $p_{0x},\ p_{0z} \in [-0.30B,\ +0.30B]$ | 与碎屑同量级：柱子埋在体内，横向必须铺开，否则会挤成一根 |
| 横截面半宽 | $0.08$ 到 $0.30$ 世界单位 | 与半长 $4$ 到 $14$ 相除，长宽比 $13$ 到 $175$，这是"丝"的读法来源 |
| 截面扰动 | $p_{0z}$ 那一轴乘 $0.7$ 到 $1.3$ | 截面不必是正方形 |
| 轴向半长 | 名义 $1.2$ 到 $6.7$（**半长**，世界单位），再乘 §5.5 的方向/先后倍率 | 最长的一根全长 $13.4$ = 舰长 $1/4$ |
| 生长 | $\text{len} = \text{half}_y \cdot \text{smoothstep01}\!\big(\text{clamp01}(\text{phase} / 0.35)\big)$ | 长度从零长到全长，占寿命前 $35\%$，即"从体中长出来" |

**命题 3（内端不变式）**：光柱的方块中心取

$$\text{pos}_y = p_{0y} + \text{dirY} \cdot \text{len} \tag{16}$$

则由 (16)，方块沿 $Y$ 跨越 $\big[\,p_{0y},\ p_{0y} + 2\,\text{dirY}\,\text{len}\,\big]$，其内端恒为 $p_{0y}$，**与长度无关**。
于是生长表现为外端单方向外移，而不是整根柱子在原地膨胀。

（实例矩阵因此只含平移，不含旋转与缩放；缩放全部走实例属性 `aHalf`。这与碎屑一致，
也是着色器 `world = model * aInst * vec4(aPos * aHalf, 1.0)` 现有的写法，无需改动。）

## 8. 两条硬约束

### 8.1 去程窗口必须在 $\tau^\ast$ 之前收干净

光柱的锚点矩阵取 `shipWireModel`（不含滑入与拉伸的**逻辑位姿**）。这份矩阵在 $\tau^\ast$ 那一帧会**跳变**
（舰体的 `position` 被传送到落点，相距约 $650$ 世界单位）。若还有活着的柱子，它们会被整体瞬移到落点那一侧。

(7) 的 $\min$ 正是为这条服务：$t_0$ 最早 $1.0565$、最晚 $1.3542$，对应的寿命上限 $P\_\text{LIFE} = 0.50$ 与窗口余量 $\tau^\ast - 1.3542 = 0.1958$，取小之后**所有柱子的消亡时刻都不晚于 $\tau^\ast$**。

> 这与外壳当初那次翻车是同一类错误：**给一个效果延长寿命之前，先查它挂的矩阵里有没有随时间变的位移**。
> 外壳是拖过了 $\tau^\ast$、被滑入的偏移甩在起点一侧；光柱则用 $\min$ 从构造上排除了这种可能。

### 8.2 长度与淡出：去程按寿命比例，抵达按全局时间表

**去程**的窗口长短差很多（逐根 $0.196$ 到 $0.494$ 秒），所以四个包络都用**相对自身寿命**的比例：

| 常量 | 现值 | 作用 |
|---|---|---|
| `P_GROW_F` | $0.35$ | 长出占寿命前 $35\%$ |
| `P_FADE_IN_F` | $0.20$ | 淡入占寿命前 $20\%$ |
| `P_FADE_OUT_F` | $0.20$ | 淡出占寿命末 $20\%$ |
| `P_SHRINK_F` | $0.40$ | 末尾"缩掉"占寿命末 $40\%$（三个轴一起缩，长宽比不变） |

**消失靠"缩掉"而不是只靠淡化**：寿命只有 $0.2$ 到 $0.5$ 秒，只淡化会读成"闪一下"（实测踩过）。现在缩小（末 $40\%$）与淡出（末 $20\%$）重叠，读出的是"亮着缩小然后消失"。

**约束**：$P\_\text{GROW\_F} + P\_\text{SHRINK\_F} \le 1$（现值 $0.75$，留出相位 $0.35$–$0.60$ 的全长保持段），
且 $P\_\text{FADE\_IN\_F} + P\_\text{FADE\_OUT\_F} \le 1$，否则没有"全亮"的那一段，柱子会一路暗着。

（碎屑那条"`D_FADE_OUT` 必须明显小于 `D_LIFE_MIN`"是同一条规矩的绝对秒数版本；
光柱因为窗口短得多，必须改成比例版本。）

**抵达段不适用本条。** 它的收尾是**全局**的（§5.5）：长度与亮度都由 $f(\tau)$ 控制，与每根柱子自己的寿命无关 —— 这正是"整批一起变短、到线框消失那一刻一起归零"的实现方式。上面四个 `P_*_F` 常量对抵达段**不生效**（它们只作用于去程）。

### 10.2 调用点

`WarpPillarDraw` 的 `logicalModel` 参数传的是 **「带材质的舰船出现的那张面」的逻辑位姿**：

```cpp
const float pillarSlide =
    (gWarp.tau > warp_sc::TAU_STAR) ? (-warp_sc::SLIDE_ARRIVAL_K * gShipBowOffset) : 0.0f;
const glm::mat4 pillarPlane =
    glm::translate(glm::mat4(1.0f), ship.RenderForward(alpha) * pillarSlide) * shipWireModel;
```

也就是抵达滑入的**起点** —— 离落点 `SLIDE_ARRIVAL_K` 个半舰长（$2.5 \times 27.077 \approx 67.7$）处，正是材质最初出现的那张面。
偏移只对抵达段生效；$\tau^\ast$ 之前传逻辑位姿本身（去程的柱子该在出发位姿上）。

⚠️ **不能直接传 `shipWireModel`**：那是舰体中垂面的位姿，柱子会落在舰体身上，读起来就变成"幽灵舰体本身"了。这一条是实测踩出来的。

⚠️ **必须在 `WarpPillarDraw` 内部把锚点还原到世界尺度。**`shipWireModel` 里含 `GetModelMatrix` 的 `scale(0.0005)`，而本模块的实例坐标（`p0`、`disp`、`half`）一律按**世界单位**写，量级 $0.1$ 到 $30$。两者直接相乘会把整组柱子缩到 $1/2000$（$0.0005 \times 30 = 0.015$ 世界单位），塌成舰体原点附近一个亚像素的点，**画面上完全看不出变化**。碎屑那边是在 `WarpDebrisAnchor` 里做同一件事：

```cpp
debrisAnchor = shipModel * glm::scale(glm::mat4(1.0f), glm::vec3(1.0f / 0.0005f));
```

所以 `WarpPillarDraw` 要先把 `logicalModel * glm::scale(glm::mat4(1.0f), glm::vec3(1.0f / 0.0005f))` 算出来再喂给 `model`。调用点仍然只传"逻辑位姿" —— 还原尺度是 draw 的内部细节。

**这一条是实测踩出来的**：第一版直接传了 `shipWireModel`，后果就是"改完画面上什么都没发生"。

### 10.3 实例缓冲必须扩容

碎屑的实例缓冲按 `D_COUNT` 分配；光柱两段窗口各要 `P_COUNT` 条。虽然两段窗口的时间区间不重叠
（去程止于 $\tau^\ast = 1.55$、抵达起于 $4.89$），仍按"碎屑 + 两段窗口"之和分配，留出以后把窗口改重叠的余量。

## 11. 验收判据

逐条目视，每条只看一件事：

| 编号 | 看什么 | 通过的样子 |
|---|---|---|
| A1 | 去程的光柱出现位置 | 只出现在"正在溶解的那条带"里，带扫过之后柱子留在后面继续漂 |
| A2 | 去程的伸长方向 | 中垂面之前朝舰首伸、之后朝舰尾伸；两端各有柱子**探出舰体** |
| A3 | 去程的漂移 | 缓缓（起步不急）向外发散；向后的那部分比例与 §5.2 的分界常量一致 |
| A4 | 去程的收尾 | 全亮白闪那一帧，画面上没有残留的光柱 |
| B1 | 抵达的出现时刻 | **骨架长满并静止等待之后**才出现（$4.89 = \text{WIRE\_GROW\_TIME} + \text{HOLD\_TIME}$），而材质开始填充之前就已经在（材质 $4.99$）—— 光柱比材质早 $0.10$ 秒 |
| B2 | 抵达的停止出生 | 舰体材质出现约一半之后，不再有新柱子冒出来（$5.14 = \text{T\_WIRE\_END} + 0.5\,\text{FILL\_TIME}$） |
| B3 | 抵达的被盖住 | 材质填到哪里，那里的柱子就被盖住；不需要任何额外逻辑（§2.2 命题 1） |
| B4 | 抵达的收尾 | 长度包络从材质一半（$5.14$）起整批变短，到 $5.62$（**与线框同一时刻**）缩到 $0$ |
| B5 | 抵达的柱长与粗细 | 出生越晚的越小；材质一半之后就只剩缩短后的"小碎块"，而且**消失时仍然是长方体**（横截面按 $f^{0.70}$ 与长度同时归零）。见 §5.5 |
| B6 | 舰体归位的节奏 | 拉伸复原与材质填满在 $5.29$ 完成，**滑入要到 $5.44$ 才贴合骨架**（`SLIDE_FALL = 0.45`，末段 $0.15$ 秒纯滑动）；舰首进框在 $5.04$，拉伸从 $5.09$ 开始复原 |
| C1 | 亮白带 | 侧视时柱子沿视线叠成**一条连续的亮白带** —— 这是**目标形态**，不是瑕疵；它同时顶替了"折跃处的空间裂纹"，因此**不再单独做裂纹效果**。不够亮、断成一根根，就抬 `U_PILLAR_GAIN` |
| C2 | 不误伤 | 碎屑、骨架、幽灵、材质、影子、太阳日冕都与改动前一致 |

**关于"白带"与视角。**"白带"出现在视线**垂直于舰轴**的视角（侧视、环绕）；跟随视角下舰轴大致沿视线，柱子会叠成一个**集中的亮团**而不是横带。两者是同一个机制（柱子在视线方向上叠加）的不同投影，不需要为其中任一种另做处理。若要让跟随视角也读出横带，唯一的办法是让柱子**横向铺得更开**（加大 `P_SPAWN_W`），但那会削弱"从舰体里长出来"的读法，属于取舍而非修正。

## 12. 可调常量与待定

| 项 | 现状 | 怎么调 |
|---|---|---|
| **骨架静止等待**（`HOLD_TIME`） | $2.87$ 秒（对齐 SC2 录屏） | 这是**整个后半段的总旋钮**：`T_WIRE`、`T_WIRE_END`、光柱出现的时刻、`T_TOTAL` 全是派生量，改它一个，后半段整体平移。想紧凑就调到 $1.5$ 左右 |
| 漂移分界（`P_DRIFT_Y_K`） | $0.50$（只有舰尾 $1/4$ 向后，**已由观察锁定**） | 回到前后各半填 $0$；想更少向后就往上加（$1.0$ 即全部向前） |
| 抵达的轴向漂移 | 统一向舰首（(13)） | 若抵达也应是分向的，把 (13) 换成 (11) 的 `dirY` |
| 抵达的柱长（`P_ARRIVE_LEN_K1`） | $0.50$ | 材质恢复一半时长度还剩多少；往上调 = 缩得更慢、更晚才短。横截面另有 `P_ARRIVE_WIDE_P`（$0.70$），往下调 = 更粗 |
| 根数 / 尺寸 / 增益 | §9 的现值 | 纯观感，按画面收 |
| 光柱那张"面"的方位（`P_PLANE_SIDE`） | $-1.0$（落点后方 = 材质出现的位置） | 填 $+1.0$ 会跑到落点前方 $67.7$ 处，与材质脱节（§10.2） |

## 附：本方案改过的四次判断（留档）

1. **"六向随机喷出"**（初版）：照抄碎屑的速度模型。**错**：光柱只有轴向伸长，没有随机朝向。
2. **"伸长按 $g = 0.75$ 分"**：为了让伸长与漂移共用一条分界。**被观察推翻**：伸长以**中垂面**分，前后各半。
3. **"分界就是原点平面，靠 `sign` 白捡"**：假设模型原点偏心。**探针推翻**：原点实测在正中（`origin_from_bow = 0.500`），
   所以任何非对称分界都必须是显式常量，不能依赖坐标系。
4. **"柱长"与"锚点矩阵的尺度"各踩一次**：
   - $P\_\text{LEN\_MIN}$ / $P\_\text{LEN\_MAX}$ 是**半长**（顶点着色器是 `aPos * aHalf`，`aPos \in [-1,1]`）。
     第一版把"全长 $13.4$"填了进去，于是"最长 $= 1/4$ 舰长"变成"$1/2$ 舰长"，背对那批也从 $1/8$ 顶到 $1/4$。
   - 光柱照抄了碎屑的实例布局，却漏了锚点的**尺度还原**：碎屑传进 `model` 的是 `shipModel * scale(1/0.0005)`，
     因为舰体模型矩阵含 `scale(0.0005)`。第一版直接传 `shipWireModel`，整组柱子被缩到 $1/2000$、塌成舰体原点
     附近一个亚像素的点，**画面完全没变化**（`WarpDebris.h` 的文件头本来就写着这条警告）。判据：**签名只说明"要一个 mat4"，不说明它该在哪个尺度里** —— 去读调用点怎么造这个矩阵。
