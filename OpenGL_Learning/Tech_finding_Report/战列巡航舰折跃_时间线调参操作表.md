## 1. 时间线总览

| 阶段 | 标称区间 | 主导通道 | 该通道的实际区间（当前值） |
|---|---|---|---|
| 蓄能 | [0.00, 0.45) | `u_c` 电流外壳 | [0.00, 0.62]：升 0.40 / 平 0.05 / 降 0.17 |
| 隐没 | [0.45, 0.65) | `u_v` 白化与拉伸 | [0.45, 0.68]：升 0.15 / 平 0.02 / 降 0.06 |
| 闪现 | 峰值在 τ\* = 0.65 | `u_g` 全屏白 | 自 0.60 线性升 0.05 到顶，再幂律衰减 0.09 至 0.74 |
| 线框 | [0.65, 1.00) | `u_w` 线框 | [0.62, 1.08]：升 0.08 / 平 0.25 / 降 0.13 |
| 实体化 | [1.00, 1.25) | 几何退回 + 拉伸回落 | 前沿退回 [1.00, 1.20]；拉伸回落 [1.00, 1.25] |

三个结构性锚点：**τ\* = `TAU_STAR` = 传送那一帧 = 闪现峰值**；**`T_WIRE_END` = 1.00 = 材质开始长回来**；**`T_TOTAL` = 1.25 = 时间线结束**。

每一条通道都刻意**越出**它所属的标称分段，让相邻效果搭接，避免出现"两个通道都接近 0"的空档。搭接规律是：前一个通道开始淡出的时刻等于后一个通道开始上升的时刻。

## 2. 主旋钮（决定各阶段时长）

改任意一行，其余全部自动跟随。

| 旋钮 | 现值 | 直接控制 | 自动跟随的量 | 副作用与约束 |
|---|---|---|---|---|
| `T_CHARGE` | 0.45 | 蓄能段总长；电弧上升段 = `T_CHARGE − 0.05` | `TAU_STAR`、`T_WIRE_END`、`T_TOTAL`、`FLASH_*`、`FRONT_GEO_START`、`KICK_*`、`SHAKE_START`、`STRETCH_RISE`、四行通道表 | τ\* 整体后移；`anticipation` 的 1.5 世界单位退距摊得更慢 |
| `T_VANISH` | 0.20 | 隐没段；`u_v` 上升段 = `T_VANISH − 0.05` | 同上 | 约束 `T_VANISH > 0.15`，否则 `STRETCH_RISE` 落到隐没段之外 |
| `T_WIRE` | 0.35 | 线框段；**τ\* 不动** | `T_WIRE_END`、`T_TOTAL`、`W_F0`、`W_F1`、四行 `A_*`、`STRETCH_HOLD_END`、前沿退回的起点 | 约束 `T_WIRE ≥ 0.30`，否则 `KICK_END` 越出线框段 |
| `T_APPEAR` | 0.25 | 实体化段；**τ\* 不动** | `T_TOTAL`、`A_F1`、`FRONT_RETREAT`（0.8 倍）、`STRETCH_FALL`（1 倍） | 约束 `T_APPEAR ≥ 0.13` |

**只改后两个最省事**：τ\* 不动，于是闪现、前沿起点、FOV 冲击、抖动、拉伸上升全部不受影响。

## 4. 段内"形状"旋钮（不改总时长，只改段内分布）

| 想达到的效果 | 改哪里 | 刻度与约束 |
|---|---|---|
| 电弧满强度停更久 | `C_R1 = T_CHARGE − 0.05f` 的偏移 | 平台时长就等于该偏移；改 0.25 即满强度 0.25 s。`C_F0` 不要动 |
| 电弧更亮 | cpp 的 `uShellStrength = wch.c * 2.0f`、`rimStrength = 0.6f * (1 + 4·wch.c)` | 这是亮度，不是时长 |
| 白化更"猛" | 不能单独改：`V_R1 = FLASH_RISE`，与闪现上升段共用同一个量 | 该共用是有意的——白化到顶的瞬间正是闪现开始上升的瞬间 |
| 线框自艏扫到艉更快或更慢 | `WIRE_GROW_TIME` | 与 `T_WIRE` 无关的独立一根；只要 ≤ `T_WIRE` 就能在段内长完 |
| 线框满强度停更久 | `W_F0 = T_WIRE_END − 0.05f`、`W_F1 = T_WIRE_END + 0.08f` | 下降段 = `W_F1 − W_F0` |
| 材质长回来更慢 | `FRONT_RETREAT = 0.8f * T_APPEAR` 的系数 | 比改 `T_APPEAR` 更精准；系数必须 ≤ 1，否则退回会越过 `T_TOTAL` |
| 拉伸收回更慢 | `STRETCH_FALL = T_APPEAR` | 想独立控制就写成固定秒数 |
| 拉伸提前或推后起 | `STRETCH_RISE = TAU_STAR − 0.15f` 的 0.15 | 必须 < `T_VANISH` |
| 闪现上升或衰减更短 | `FLASH_RISE = TAU_STAR − 0.05f`、`FLASH_END = TAU_STAR + 0.09f` | 前者同时是 `u_v` 到顶时刻 |
| 闪现衰减形状 | `FLASH_POW` | 越大越"前重后轻"；须 > 1 才能让末端斜率归零 |
| 溶解前沿提前起 | `FRONT_GEO_START = TAU_STAR − 0.12f` 的 0.12 | 必须落在 (0, `TAU_STAR`) |
| 推镜与抖动的起落 | `KICK_START − 0.07`、`KICK_END + 0.30`、`SHAKE_START − 0.02`、`SHAKE_DECAY` | `KICK_END ≤ T_WIRE_END`；`SHAKE_START < TAU_STAR` |
| 噪声侵蚀的粗糙程度 | `NOISE_W` | 同时决定前沿的取值域 `[−NOISE_W/2, 1 + NOISE_W/2]`，改大改小都自动自洽 |
| 材质剥离带的空间宽度 | `FRONT_LEAD` | 必须 > 0，否则 `smoothstep` 的 `edge0 < edge1` 被破坏 |
| 切口发光带宽 | shader 的 `uEdge` 与 cpp 里 `0.06f` | 空间量，不是时间量 |

## 5. 改完必查

1. **每行 `r1 ≤ f0`**。最紧的是 `u_w` 行，它退化到 `T_WIRE ≥ 0.10`。这条一旦破，峰值达不到 1 且**不报错**，只会看到那一段莫名其妙偏暗。
2. **`KICK_END ≤ T_WIRE_END`**，退化到 `T_WIRE ≥ 0.30`。
3. **`T_APPEAR ≥ 0.13`**，保证 `A_F0 ≤ A_F1`（`A_F0 = T_WIRE_END + 0.10`，`A_F1 = T_TOTAL − 0.03 = T_WIRE_END + T_APPEAR − 0.03`）。
4. **所有"斜率"的宽度 ≥ `DT_MAX = 1/30 ≈ 0.0333 s`**。当前最窄的三条斜率是闪现上升 0.05、隐没下降 0.06、实体化上升 0.07，都还有余量。**平台短于一帧是允许的**（隐没的平台只有 0.02）：被跨过的只是"恰好取到 1"这件事，取值仍 ≥ 0.99，肉眼不可辨。钉帧只保护 τ\* 一个时刻，其他沿一概不保。
5. **五个锚点行不要动**：`C_F0`、`V_R0`、`V_F0`、`W_R0`、`STRETCH_HOLD_END`，以及 `A_F1 = T_TOTAL − 0.03`。前四个是交棒点（动了会出现空档），最后一个是为"钉住一帧"预留的 0.03 s 余量。

改完在 **Debug|x64** 下跑一遍，控制台应出现 `===== warp self test: all OK =====`（P1–P7，共 37 条断言）。自测全部用容差比较，常量改写成表达式带来的 ≤1 ulp 差别不会触发失败。

## 6. 常见诉求速查

| 诉求 | 一处改动 |
|---|---|
| 想看清电弧 | `T_CHARGE` 加大（拉长上升段）；要满强度停久则同时改 `C_R1` 的偏移 |

## 8. 已知未接线与注意事项

- **`wch.a` 目前没有消费者**。cpp 里被读取的通道只有 `solid`、`c`、`v`、`w`、`g`；`a` 只在 `sample()` 里算出来。因此实体化段现在真正由 `FRONT_RETREAT`（几何退回）与 `STRETCH_FALL`（拉伸回落）驱动，**A 行四个数改了对画面没有影响**。
- **`WARP_MIN_DIST` 尚未被引用**，它属于阶段 6（落点合法性：与火星球求交后钳制 `D_eff`，不合法则播一次红闪）。
- **`TIME_SCALE` 是整段慢放**（置 0.1 即放慢 10 倍），与"只拉长某一段"是两回事：它不动任何几何关系，只是把同一条参数化曲线拉长，用来逐帧确认遮盖与生长。调试完记得调回 1.0。
- **冷却自 τ\* 起算**，不是自按键起算：按 T 之后要过 `TAU_STAR + WARP_COOLDOWN` 秒才能再折跃。
- **工程从未启用面剔除**（`glEnable(GL_CULL_FACE)` 一次都没有），所以各处的 `glCullFace` 都是空操作，所有物体双面绘制，太阳日冕依赖这一点。折跃相关的 pass 里也不要"顺手还原"剔除状态——历史上线框 pass 结尾的一句 `glEnable(GL_CULL_FACE)` 曾让太阳日冕永久消失。

## 9. 一个完整示例：把蓄能段从 0.45 拉到 0.90

只改 `T_CHARGE = 0.45f` 这一行（`Warp.h`，`T_VANISH` 之上），其余自动变成：

| 量 | 原值 | 新值 |
|---|---|---|
| `TAU_STAR` / `T_WIRE_END` / `T_TOTAL` | 0.65 / 1.00 / 1.25 | 1.10 / 1.45 / 1.70 |
| `FLASH_RISE` / `FLASH_END` | 0.60 / 0.74 | 1.05 / 1.19 |
| `FRONT_GEO_START` / `STRETCH_RISE` | 0.53 / 0.50 | 0.98 / 0.95 |
| `KICK_START` / `KICK_END` / `SHAKE_START` | 0.58 / 0.95 / 0.63 | 1.03 / 1.40 / 1.08 |
| `u_c` 四项 | 0.00 0.40 0.45 0.62 | 0.00 0.85 0.90 1.07 |
| `u_v` 四项 | 0.45 0.60 0.62 0.68 | 0.90 1.05 1.07 1.13 |
| `u_w` 四项 | 0.62 0.70 0.95 1.08 | 1.07 1.15 1.40 1.53 |
| `u_a` 四项 | 0.98 1.05 1.10 1.22 | 1.43 1.50 1.55 1.67 |

电弧的外壳可见时长由 0.62 s 变为 1.07 s，而隐没、线框、实体化三段的内部结构完全不变（它们由 `T_VANISH`、`T_WIRE`、`T_APPEAR` 决定）。若同时要"满强度保持更久"，再把 `C_R1` 的偏移由 0.05 改成 0.25。
