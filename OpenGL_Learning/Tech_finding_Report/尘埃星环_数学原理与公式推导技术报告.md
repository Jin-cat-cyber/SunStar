## 0. 引言

尘埃星环和行星大气散射共用**同一套体积渲染骨架**：沿视线 ray-march，逐点采样一个**密度场** $\rho$，累加**单次散射**光，并用 Beer–Lambert 衰减透射率。区别在于大气壳是"包围球"，星环是"**环形圆柱薄带**"（环面体去掉中间孔），且它的密度场是一堆**可分离因子 × 湍流噪声**的乘积。

本文按渲染顺序，把每一步的数学和 `ring_frag.shader` 代码行逐一对应。

---

## 1. 视线重建（屏幕像素 → 世界射线）

全屏 quad 每个像素要还原成一条穿入场景的射线。

$$
\text{ndc} = 2\cdot\frac{\text{gl\_FragCoord.xy}}{\text{resolution}} - 1
$$

用 `invProjView = (P\cdot V)^{-1}` 把 NDC 反推回世界空间**远点**：

$$
\text{farW} = \Pi\Big(\text{invProjView}\cdot(\text{ndc},\,1,\,1)\Big),\qquad
\hat r = \frac{\text{farW} - \text{camPos}}{\lVert \text{farW} - \text{camPos}\rVert}
$$

$\Pi(\cdot)$ 表示除以齐次分量（`/w`）。$\hat r$ 就是该像素的视线方向。

```glsl
vec2 ndc = gl_FragCoord.xy / resolution * 2.0 - 1.0;
vec4 farW = invProjView * vec4(ndc, 1.0, 1.0);
farW /= farW.w;
vec3 rd = normalize(farW.xyz - camPos);
```

---

## 2. 体积包围盒：slab 法求射线与盒的交

先把星环装进一个**轴对齐包围盒**（沿 y 轴竖立），半边长：

$$
\mathbf e = (\text{ringOuter},\; \text{ringHalfHeight},\; \text{ringOuter})
$$

**slab 法**：逐轴求射线进入/离开该对平行平面的参数 $t$，取交。

对 $k\in\{x,y,z\}$，设盒范围 $[m_k, M_k]$（$m = c - e,\; M = c + e$）：

$$
t^{\min}_k = \min\!\Big(\frac{m_k - o_k}{r_k},\ \frac{M_k - o_k}{r_k}\Big),
\qquad
t^{\max}_k = \max\!\Big(\frac{m_k - o_k}{r_k},\ \frac{M_k - o_k}{r_k}\Big)
$$

整体进入/离开：

$$
t_{enter} = \max_k t^{\min}_k, \qquad t_{exit} = \min_k t^{\max}_k
$$

- 若 $t_{enter} > t_{exit}$ → 射线没打中盒，`discard`；
- 相机在盒内时 $t_{enter}$ 为负，clamp 成 $0$（`max(tb.x, 0.0)`）。

```glsl
vec2 tb = rayBox(camPos, rd, ringCenter, halfExt);
float tEnter = max(tb.x, 0.0);
float tExit  = tb.y;
if (tEnter > tExit) discard;
```

## 3. 火星本体遮挡：raySphere 截断采样终点

星环中央是火星，射线若打到火星球，**环在火星背后那段就不该采样**（否则穿模）。用球相交求行星最近交点：

$$
\mathbf{oc} = o - c,\quad b = \mathbf{oc}\cdot\hat r,\quad c_2 = \mathbf{oc}\cdot\mathbf{oc} - R^2,\quad D = b^2 - c_2
$$

$$
t_{planet} = \begin{cases}
-b - \sqrt{D} & D \ge 0 \\
-1 & D < 0
\end{cases}
$$

若命中，把采样终点夹到行星表面：

$$
t_{end} = \min\big(t_{exit},\ t_{planet}\big)
$$

```glsl
float tPlanet = raySphere(camPos, rd, ringCenter, planetRadius);
float tEnd = tExit;
if (tPlanet > 0.0) tEnd = min(tEnd, tPlanet);
```

> 这是"**体积遮挡用解析相交自己算**"的关键——不能用深度缓冲判体积遮挡（深度只管盒面，管不了星环这种要被行星从中间截断的体积）。

## 4. 密度场 $\rho(\mathbf p)$

在环带内（$R_{in} < r < R_{out}$，$|h| < H$，其中 $H = \text{ringHalfHeight}$），密度是多因子乘积：

$$
\rho(\mathbf p) \;=\; \rho_{rad}(u)\cdot \rho_{vert}(h)\cdot \big[0.5 + 0.7\,n\big]\cdot \sigma_{spill}
$$

各量定义如下。

### 4.1 径向坐标与相对位置

取环轴为 y 轴（过 `ringCenter`），采样点 $\mathbf p$ 的**径向距离**与**高度偏移**：

$$
r = \Big\lVert (p_x - c_x,\ p_z - c_z)\Big\rVert, \qquad
h = p_y - c_y
$$

相对位置（内缘 $0$ → 外缘 $1$）：

$$
u = \frac{r - R_{in}}{R_{out} - R_{in}}
$$

### 4.2 径向包络 $\rho_{rad}$（软内缘 + 软外缘）

用 smoothstep 让内外边缘渐隐，中心最浓：

$$
\rho_{rad}(u) \;=\; \mathrm{S}(0,\;0.15,\;u)\cdot\big(1-\mathrm{S}(0.6,\;1.0,\;u)\big)
$$

其中 $\mathrm{S}(a,b,x)$ 是三阶 smoothstep：

$$
\mathrm{S}(a,b,x) = \mathrm{clamp}\!\big(\tfrac{x-a}{b-a},\,0,\,1\big)^2 \cdot \big(3 - 2\,\mathrm{clamp}\!\big(\tfrac{x-a}{b-a},\,0,\,1\big)\big)
$$

```glsl
float radial = smoothstep(0.0, 0.15, relDist) * (1.0 - smoothstep(0.6, 1.0, relDist));
```

### 4.3 垂直剖面 $\rho_{vert}$（高斯薄带）

环在竖直方向是**高斯衰减**，中心平面最浓、上下稀：

$$
\rho_{vert}(h) \;=\; \exp\!\Big(-2\,\frac{h^2}{H^2}\Big)
$$

```glsl
float vertical = exp(-(h*h) / (ringHalfHeight * ringHalfHeight) * 2.0);
```

### 4.4 湍流噪声 $n$（fbm，搅出"灰尘云絮"）

用 **2D value noise 做 5 层分形叠加（fbm）**，再加 smoothstep 压成云絮状：

$$
n \;=\; \mathrm{S}(0.3,\,0.8,\;\mathrm{fbm}(\mathbf u)), \qquad \mathbf u = (\text{offset})\cdot 0.045 + \text{drift}
$$

- `offset = p.xz - ringCenter.xz`，缩放 `0.045` 控制噪声频率；
- `drift = (0.03, 0.02)·time` 让云絮缓慢流动。

**fbm**（5 个 octave，频率 ×2，振幅 ×½）：

$$
\mathrm{fbm}(\mathbf p) = \sum_{i=0}^{4} 0.5^{\,i+1}\,\mathrm{noise}\big(\mathbf p_i\big),
\qquad
\mathbf p_{i+1} = 2\,\mathbf p_i + (1.7,\,9.2)
$$

**value noise**：网格点哈希 `hash(p)=fract(sin(p·(127.1,311.7))·43758.5453)`，双线性插值并用平滑曲线 `u = f²(3-2f)` 消除方块感：

```glsl
vec2 uv = offset * 0.045;
float n = fbm(uv + vec2(time * 0.03, time * 0.02));
n = smoothstep(0.3, 0.8, n);
```

### 4.5 掠射系数 $\sigma_{spill}$（视线越平，环越亮）

当视线接近水平（掠着星环平面看）时，灰尘被"拉长"显得更亮：

$$
\sigma_{spill} \;=\; 0.35 + 0.65\,\mathrm{S}(0,\,0.5,\,|\hat r_y|)
$$

```glsl
float grazing = abs(rd.y);
float spill = 0.35 + 0.65 * smoothstep(0.0, 0.5, grazing);
float d = radial * vertical * (0.5 + 0.7 * n);
d *= spill;
```

## 5. 光照与阴影

### 5.1 太阳方向

$$
\hat L = \frac{\mathbf{L}_{sun} - c}{\lVert \mathbf{L}_{sun} - c\rVert}
$$

### 5.2 朗伯式环面明暗 $\mathrm{lit}$

用采样的**径向朝外法线** $\hat o = \frac{\mathbf p - c}{\lVert \mathbf p - c\rVert}$ 与太阳方向的点积做漫反射模拟：

$$
\mathrm{lit} \;=\; 0.4 + 0.6\,\max\big(\hat o \cdot \hat L,\; 0\big)
$$

```glsl
vec3 outward = normalize(p - ringCenter);
float lit = 0.4 + 0.6 * max(dot(outward, sunDir), 0.0);
```

### 5.3 点光源阴影（硬二值）

复用点光源阴影 cubemap：比较"到太阳的实际距离"与"深度贴图里存的遮挡深度"（线性深度 × `far_plane`）：

$$
s(\mathbf p) = \begin{cases}
1 & \lVert \mathbf p - \mathbf L\rVert - b \;>\; \text{depth}(\mathbf p - \mathbf L)\cdot \text{far\_plane} \\
0 & \text{否则}
\end{cases}, \qquad b = 21.0
$$

```glsl
float ShadowCalculation(vec3 p) {
    vec3 fragToLight = p - sunPos;
    float currentDepth = length(fragToLight);
    float closestDepth = texture(depthMap, fragToLight).r * far_plane;
    float bias = 21.0;
    return (currentDepth - bias > closestDepth) ? 1.0 : 0.0;
}
```

### 5.4 颜色色调 $\mathbf T_e$

内外缘色调插值：内缘暖橙，外缘转浅：

$$
\mathbf T_e \;=\; \mathrm{mix}\big((1.0,0.75,0.5),\ (1.0,0.95,0.8),\ \mathrm{S}(0.15,0.6,u)\big)
$$

```glsl
vec3 tint = mix(vec3(1.0, 0.75, 0.5), vec3(1.0, 0.95, 0.8), smoothstep(0.15, 0.6, relDist));
```

## 6. 单次散射累积 + Beer–Lambert（主循环）

对每个采样点，它能**散射进视线**的光为：

$$
\mathbf C_{in}(\mathbf p) \;=\; \Phi_{sun}\cdot \mathbf T_e \cdot \rho \cdot \big(1-s\big)\cdot \mathrm{lit}
$$

**进入相机前还要被沿途灰尘衰减**（透射率 $T$），于是该点贡献：

$$
\mathbf C_{out} \mathrel{+}= \Phi_{sun}\,\mathbf T_e\,\rho\,(1-s)\,\mathrm{lit}\cdot T\cdot \Delta t\cdot 0.22
$$

```glsl
float scatter = d * (1.0 - shadow) * transmittance * lit;
light += sunColor * tint * scatter * stepLen * 0.22;
```

**透射率**（消光，标量系数 $\kappa = 0.025$）：

$$
T \leftarrow T\cdot \exp\!\big(-\rho\cdot \kappa\cdot \Delta t\big)
$$

```glsl
transmittance *= exp(-d * stepLen * 0.025);
```

> 符号说明：这里消光用的是**标量** $\rho\cdot\kappa$（不像大气散射的逐通道 vec3），所以 $T$ 是 `float`。散射与消光系数分开（散射乘进 `light`，消光衰减 `T`），是体积渲染的标准做法。

步长取法（64 步的中点法）：

$$
\Delta t = \frac{t_{end} - t_{enter}}{64}, \qquad t_i = t_{enter} + \frac{i + 0.5}{64}\big(t_{end} - t_{enter}\big)
$$

## 7. 输出

先算 `light` 的亮度（Rec.709 权重），作为加法混合的 alpha 参考；最终输出用**光学不透明度** $\alpha = 1 - T$：

$$
\alpha \;=\; 1 - T \quad\text{(灰尘越厚，alpha 越大，见"透过"越少)}
$$

```glsl
float intensity = clamp(dot(light, vec3(0.2126, 0.7152, 0.0722)), 0.0, 1.0);
FragColor = vec4(light, 1.0 - transmittance);
```

> 这样设置后，配合 $\alpha$ 混合，星环既能**加光（$light$）**，又能**用 $1-T$ 挡暗它后面的火星**——同大气散射修复里"输出深度/不透明度"的思路一致。

## 8. 参数速查表

| 代码变量 | 物理量 | 控制效果 |
|---|---|---|
| `ringInner = 150` | $R_{in}$ | 环内半径 |
| `ringOuter = 260` | $R_{out}$ | 环外半径 |
| `ringHalfHeight` | $H$（= `ringThickness/2`） | 环竖向半厚 |

| `steps = 64` | $N$ | 采样步数（越多越细腻） |

| `far_plane` | 阴影远平面 | 阴影覆盖范围 |
