# 大气散射全屏 Pass 遮挡修复 · 深度测试与深度输出技术报告

> 版本：SpaceShip16.0.cpp + `res/shader/00_SpaceShip/Atmosphere/atmo_frag.shader`
> 定稿日期：2026-09-07
> 配套文档：[[行星大气散射技术报告]](行星大气散射技术报告.md)（方案主体）、[[尘埃星环体积渲染参数调节说明书]](尘埃星环体积渲染参数调节说明书.md)（同套 ray-march + raySphere 遮挡范式）

---

## 一、问题现象

给火星加了"独立大气壳"全屏 Pass 之后，出现一个明显视觉 bug：

- 当相机贴近火星（进入大气壳范围）时，**镜头前景的小行星带、尘埃环、飞船被"点亮"**——仿佛大气层渲染在了它们前面；
- 最困惑的一点：把 C++ 端 `glDisable(GL_DEPTH_TEST)` 改成 `glEnable(GL_DEPTH_TEST)` 之后，**问题依旧**，小行星带照样被点亮；
- 而在没有大气 Pass 之前（仅火星前向 PBR + 菲涅尔 rim），从没有这个问题。

---

## 二、根因：片元着色器没有输出深度值

大气层是**全屏四边形 Pass**，靠 `raySphere` 判断"这条视线是否穿过大气壳"来决定 `discard`。它的问题不是"亮度"，而是**覆盖范围失控**。根本原因分成两层：

### 2.1 全屏 Pass + 加法混合，天然不受遮挡

```cpp
glEnable(GL_BLEND);
glBlendFunc(GL_ONE, GL_ONE);   // 加法混合：只加光，从不衰减背景
glDisable(GL_DEPTH_TEST);      // ← 最早版本关掉了深度测试
glDepthMask(GL_FALSE);
```

加法混合 + 关闭深度测试，意味着这个 Pass **把散射光无脑叠加到它覆盖的每个像素上**，而且**从不会被任何挡在它前面的物体遮挡**。当相机贴近火星（相机在大气壳内，见 2.2）时，任意视线的 `tAtmoEnter` 都被 clamp 成 0（"已进入壳内"），于是**全屏每个像素都穿过大气壳、都不被 discard**——散射光铺满整块屏幕，盖到的小行星/尘环/飞船自然被点亮。

### 2.2 相机在壳内 → 全屏都满足"穿过大气壳"

- 大气壳半径 = `planetRadius × atmoScale = 0.8 × 1.25 ≈ 1.0` 世界单位；
- 当相机离火星中心 < 1.0 时，相机已经在大气壳**里面**；
- 壳内视线与球交点 `raySphere` 返回 `(负值, 正值)`，`tAtmoEnter = max(atmo.x, 0.0) = 0`，`tAtmoExit` 为正；
- 于是 `tAtmoEnter < tAtmoExit` 恒成立 → **任何方向都不被 discard** → 全屏渲染。

> 这就解释了"为什么贴得近时小行星带被点亮"。但**单纯的"覆盖范围"还不是关键转折点**，真正让"开了深度测试仍然无效"的，是下面的 2.3。

### 2.3 关键：只开 `GL_DEPTH_TEST` 不够，因为片元没有"自己的深度"

深度测试的比较对象是——**每个片元当前的深度值** vs **深度缓冲里已存的深度值**。

- 若片元着色器**没有写 `gl_FragDepth`**，片元深度就等于**顶点 `gl_Position.z/w` 插值出来的窗口深度**；
- 而我们的全屏 Pass 顶点着色器是：

```glsl
gl_Position = vec4(aPos, 0.0, 1.0);   // z 恒为 0
```

- `z = 0` 映射到窗口深度值 **恒为 0.5**——**每个片元的深度都一样，且与"大气壳表面到底在哪"毫无关系**；
- 于是即便开启 `GL_DEPTH_TEST`，深度测试的比较对象是"一堆恒为 0.5 的片元 vs 场景深度缓冲"，**无法表达"大气表面在某个深度"**——它无法用来判断"小行星是不是挡在大气前面"。

**这就是"开了深度测试还是亮"的根本原因：片元没有携带真实的空间深度，深度测试无从比较。**

---

## 三、修复原理：让每个大气片元携带"它命中大气壳的最近交点深度"

要让深度测试真正生效，必须**由片元着色器主动写出大气壳的窗口深度**——即**它最近命中的大气表面在哪儿**。这样就能和场景里已有的深度（小行星、飞船、尘环、火星表面的深度都已写入帧缓冲）做标准的 `GL_LESS` 比较：

- 位于大气壳**之前**的物体其深度更小 → 大气片元被剔除 → **不会被叠加点亮**；
- 大气壳**自身**（边缘光晕、轮廓）与更远的天空 → 深度满足 → 正常渲染出光。

### 3.1 片元输出 `gl_FragDepth`

在 `atmo_frag.shader` 中，`tAtmoEnter` 求出之后写入深度：

```glsl
mat4 projView  = inverse(invProjView);
vec3 enterP    = camPos + rd * tAtmoEnter;         // 大气壳最近交点（世界坐标）
vec4 ec        = projView * vec4(enterP, 1.0);
gl_FragDepth   = ec.z / ec.w * 0.5 + 0.5;          // 归一化到窗口深度 [0,1]
```

原理要点：

- 大气壳是**一个薄体积**，我们取"最近交点"作为它的代表深度即可（对一个薄壳，近表面是最相关的遮挡深度）；
- 火星本体遮挡由 shader 内的 `raySphere(tPlanet)` 与 `tEnd = min(tExit, tPlanet)` 逻辑负责——即**大气被火星球截断**的那部分本来就由 ray-march 的终点 clamp 处理，深度输出处理的是**大气与第三方物体（小行星/飞船/尘环）之间的遮挡**；
- `gl_FragDepth` 只有在片元着色器里显式写时才生效；写了它，深度测试用的就是这个真实深度，而非全屏恒定 0.5。

### 3.2 C++ 端开启深度测试（保持只测不写）

```cpp
glEnable(GL_DEPTH_TEST);        // 原 glDisable(GL_DEPTH_TEST)
glDepthMask(GL_FALSE);          // 保持：只参与深度测试，不写回深度缓冲
```

关键点：`glDepthMask(GL_FALSE)` 保证大气 Pass **只读深度、做比较，不污染已存在的深度缓冲**——这样它不会覆盖掉火星、小行星已写好的深度。

## 四、修复清单（改动位置）

| 位置 | 改动 | 目的 |
|---|---|---|
| `atmo_frag.shader`（`tAtmoEnter` 计算后） | 计算 `projView`、`enterP`、`ec`，写 `gl_FragDepth` | 让每个大气片元携带大气壳最近交点的真实窗口深度 |
| `SpaceShip16.0.cpp`（大气 Pass，约 L852） | `glEnable(GL_DEPTH_TEST)` | 让大气片元与场景深度做 `GL_LESS` 比较 |
| （可选）`atmo_frag.shader` | 相机在壳内且视线不贴近星球轮廓时 `discard` | 防止"相机钻进壳里"导致全屏铺满大气 |

## 五、验证结果

- **修复前**：贴火星时，镜头前小行星带/尘环/飞船被大气散射点亮；开深度测试仍无效。
- **修复后**：小行星带不再被点亮；火星边缘光晕、轮廓外亮弧正常保留；大气被更近的物体正确遮挡。

---

## 六、结论 / 经验沉淀

1. **全屏/全屏几何 Pass 必须显式输出深度**，否则深度测试形同虚设——片元默认深度是 `gl_Position.z/w` 的插值，对 `vec4(aPos,0,1)` 这种全屏 quad 恒为 0.5，与场景无关。
2. **"加法混合只加光不遮光"**：体积光/大气/星环这类想做"遮蔽"的效果，不能只靠加法混合；要么写深度（遮挡第三方物体），要么在 shader 里用解析相交自己截断（遮挡星体本体，如 raySphere/rayBox）。
3. **深度测试的三要素**：开启 `GL_DEPTH_TEST`（比较开关）、片元有真实深度（`gl_FragDepth` 或顶点插值）、深度缓冲里已有场景深度。三者缺一不可。
4. **`glDepthMask` 与深度测试是两回事**：mask 控制"写不写回"，测试控制"用不用来剔除"，可以只测不写（半透明/体积 Pass 常用）。
